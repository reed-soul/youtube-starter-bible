# 中国大陆能申请 YouTube YPP 吗？

> 核对日：**2026-10-06** · 相关：[13 中国大陆创作者专章](13-中国大陆创作者专章.md) · [大陆 FAQ](13-大陆FAQ.md) · [09 变现与合规](09-变现与合规红线.md)

## 一句话答案

**【官方】** 加入 [YouTube 合作伙伴计划（YPP）](https://support.google.com/youtube/answer/72851?hl=zh-Hans) 须**居住在已推出 YPP 的国家/地区**。截至 **2026-10-06** 打开 [YPP 适用地区列表](https://support.google.com/youtube/answer/7101720?hl=zh-Hans)，可见**香港、台湾**等条目，**名单中未见「中国」**。请以**当日**官方列表与 Studio「创收」提示为准。

**【神话】**「开个 VPN / 随便改国家就能过」——本站**不提供、不鼓励**任何虚假居住或虚假税务居民安排；PIN、KYC、税表与银行同国校验会暴露不一致。【合规】

## 你要核对的两页（5 分钟）

| 步骤 | 打开 | 你要记下来的 |
|------|------|----------------|
| 1 | [适用地区](https://support.google.com/youtube/answer/7101720?hl=zh-Hans) | 有无「中国」；有无香港/台湾；你自己的日期 |
| 2 | [YPP 资格与门槛](https://support.google.com/youtube/answer/72851?hl=zh-Hans) | 现行粉/小时或 Shorts 门槛；2027 规划若有单独说明 |
| 3 | Studio → 创收 | 账号实际提示（资格以账号为准） |

频道「所在国家/地区」与居住地会影响 YPP 资格判断，详见专章 [§2.2](13-中国大陆创作者专章.md#22-国家地区到底影响什么已核对)。

## 门槛数字（以 Help 当日为准）

以下仅作**导航摘要**，**申请前必须打开原链**：

- **广告等完整创收档**（常见表述）：订阅与长视频观看时长 / Shorts 观看次数门槛，见 [如何创收](https://support.google.com/youtube/answer/72857?hl=zh-Hans) 与 [YPP 概览](https://support.google.com/youtube/answer/72851?hl=zh-Hans)。
- **拓展档（粉丝打赏等）**：部分地区有更低订阅门槛，见 [拓展 YPP](https://support.google.com/youtube/answer/13429240?hl=zh-Hans)。
- **2027 规划**：平台已公布未来门槛调整信号——**已加入**与**新申请**规则可能不同；见专章 [§3.3](13-中国大陆创作者专章.md#33-2027-规划信号) 与 [09 章](09-变现与合规红线.md)，并回官方 Blog/Help 复核。

达到数字 ≠ 自动开通：仍须通过创收政策审核、无未解除社区警示、两步验证、关联 AdSense 等。【官方】

## 和「收款」别混为一谈

- **YPP 地区资格**：能不能加入合作伙伴计划（本页）。  
- **AdSense 收款国家**：收款地址为**中国**时，官方支持**电汇**与 **Hyperwallet**——见 [AdSense 电汇收款](adsense-电汇收款.md)。  

「名单未见中国」**不等于**「中国地址一定收不到钱」；也不等于「改个国家就合法」。两套问题分开查。【官方】
