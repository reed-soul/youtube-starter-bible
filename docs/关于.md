## 编辑政策

1. **官方优先**：YouTube Help、Creator Blog、CEO 公开信等可核对来源优先于二手解读。  
2. **证据标签**：正文使用【官方】/【行业实践】/【神话】；主张与文献对照见 [SOURCES](./SOURCES.md)。  
3. **标注日期**：每页顶部有「官方核对」徽章（来自 frontmatter `verifiedAt`，超过 90 天自动提示待复核）；政策变化见 [更新日志](更新日志.md)（可 [RSS 订阅](/feed.xml)）。  
4. **不编造**：银行费、税率、YPP 名单等写不出公开出处就不写死数字；写明「须自查」。  
5. **非意见书**：税务、法律、外汇、网络合规等仅为公开框架指针，**不是**针对个人的专业意见。  
6. **不教灰产**：不提供虚假互动、虚假税务居民身份、规避本地网络管理等操作说明。
