# YouTube 收入中国个税：只讲事实边界

> 相关：[结汇便利化（已写）](adsense-电汇收款.md#safe-fx) · [W-8BEN 图解](w8ben-填写图解.md) · [13 §6](13-中国大陆创作者专章.md#_6-中国个人所得税框架) · [大陆 FAQ](13-大陆FAQ.md)

## 一句话答案

**【官方框架】** 中国税收居民取得境外所得，依法可能有申报与抵免义务；《个人所得税法实施条例》分别定义**劳务报酬、稿酬、特许权使用费、经营所得**等——**公开检索未见**把「YouTube / AdSense」钉死为唯一税目的总局公告，故**须按事实归类**，个案问税务机关或持证税务专业人士。结汇额度与材料类型见 [AdSense 电汇收款 · 结汇](adsense-电汇收款.md)，本页**不重复**结汇操作。

> **【重要】** 本文**不是税务建议**，不指导如何少报、不报或「选最省税的税目」。请咨询**办税服务厅 / 12366 / 持证税务师**。

## 所得项目：公开定义（摘录）

依据《个人所得税法实施条例》第六条（政府网文本）：

| 项目 | 条例定义要点 | 与创作者可能的关联（框架讨论，非归类结论） |
|------|--------------|---------------------------------------------|
| **劳务报酬** | 个人从事劳务取得的所得，列举含广告、技术服务、演出等 | 若实质是提供劳务/广告服务 |
| **稿酬** | 作品以图书、报刊等形式出版、发表取得的所得 | 传统出版发表；与平台广告分成通常需谨慎对照 |
| **特许权使用费** | 提供专利权、商标权、**著作权**、非专利技术等特许权的**使用权**取得的所得；提供著作权使用权取得的所得**不包括稿酬** | 若实质是许可著作权等使用权 |
| **经营所得** | 个体工商户等经营、有偿服务、承包承租及「其他生产、经营活动」 | 若以经营主体持续经营 |

来源：[实施条例（中国政府网）](https://www.gov.cn/zhengce/content/2018-12/22/content_5351177.htm)

特许权使用费所得，是指个人提供专利权、商标权、著作权、非专利技术以及其他特许权的使用权取得的所得；提供著作权的使用权取得的所得，不包括稿酬所得。

## 纳税人识别号与居民身份（公开条文）

- 《个人所得税法》第九条：有中国公民身份号码的，以公民身份号码为纳税人识别号（[全文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_901ca8faba104739bbf54e22483e6079.html)）。  
- 税总公告 2018 年第 59 号同旨（[转载](https://www.gov.cn/zhengce/zhengceku/2019-10/28/content_5445927.htm)）。  
- 居民个人 / 非居民个人的判定见《个人所得税法》第一条及实施条例相关条款——**是否构成中国税收居民，以法规与税务机关认定为准**，本站不替你下结论。

## 境外所得申报框架

**【官方】** 《个人所得税法》第十条列明应依法办理纳税申报的情形，其中包括「取得境外所得」（[同上法律文本](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_901ca8faba104739bbf54e22483e6079.html)）。

财政部、税务总局关于境外所得的具体征管口径，公开可见如 **2020 年第 3 号**等公告（抵免、申报表等）——填表与抵免计算请走官方渠道或专业人士，**本站不写「怎么填才少交」**。

入口参考：[12366 相关释义页](https://12366.chinatax.gov.cn/bzds/082/082-5-4.html)（以税务机关现行有效文件为准）。

## 和美国预扣的关系

Google 可能对**美国境内观看者**带来的适用收入预扣美国税费（[10391362](https://support.google.com/youtube/answer/10391362?hl=zh-Hans)）。中国侧是否、如何抵免外国税额，属境外所得抵免规则——**问专业人士**。字段级美表 → [W-8BEN 图解](w8ben-填写图解.md)。
