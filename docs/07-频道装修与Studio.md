## 5分钟速读

> 先扫这几条再往下精读；细节与证据等级见正文。

- 装修顺序：先有可代表的内容，再皮；频道页是转化落地页。
- 预告片给未订阅访客；「从这里开始」列表给新观众最短路径。
- 单视频诊断序：流量来源 → 分来源 CTR → Intro → 留存曲线 → 再决定 A/B。
- 曝光（Impressions）是站内缩图展示；外链观看不一定产生印象。
- 2026 工具：Ask Studio、A/B、动态缩图等——AI 建议需人审。
- 灰按钮先查高级功能（advanced features）与验证，不要迷信「重置」。

## 1. 装修优先级：先内容后皮

冷启动常见浪费：花两周做横幅，零上传。正确顺序：

1. 至少数条能代表定位的视频  
2. 头像 + 可读频道名 + About 第一句  
3. 「从这里开始」播放列表  
4. 未订阅预告片  
5. 精修横幅与分区  

装修是**转化优化**，不是开工许可证。

## 2. Home 布局

**【官方】** 可自定义频道布局：为未订阅者设置 **频道预告片（trailer）**、为回访订阅者设置 **Spotlight**、以及多个内容分区（数量上限以当前产品为准，常见约十余个量级）。

**建议顺序（通用冷启动）**

1. Trailer（未订阅）  
2. Spotlight（老粉：最新或系列入口）  
3. 旗舰播放列表 / 核心桶  
4. 最新长视频  
5. Shorts  
6. 「从这里开始」  
7. 播客列表（若有）  
8. 直播回放（若有）

## 3. 预告片 · 横幅 · 头像 · About

### 预告片（约 30–60 秒）

1. 你是谁/给谁（1 句）  
2. 每期得到什么（1 句）  
3. 切最强内容高潮 5–15 秒  
4. CTA：订阅 + 去「从这里开始」  

**【官方】** 同一观众看过一次后，预告片通常不会反复强弹。

### 横幅

- 系列/品类一句话 + 更新节奏（「每周日上新」）  
- 注意不同设备裁切安全区（以 Studio 预览为准）  
- 少放二维码墙；关键信息放大  

### 头像

- 小尺寸可辨的符号或清晰人脸  
- 与内容调性一致  

### About

- 第一句：品类承诺  
- 更新频率  
- 代表播放列表链接  
- 商务邮箱（可选）  
- 禁止关键词堆砌

## 4. 结束画面与卡片

**【官方 · End screen】**

- 视频通常需达到最短时长门槛（常见 ≥25 秒）  
- 元素出现在最后约 **5–20 秒**  
- 可含：视频、播放列表、订阅、频道、外链（外链常需 YPP）等；数量与类型有上限  
- 最佳实践：相关推荐、口播 CTA、预留画面干净区域、可错峰出现元素  
- 在分析「互动」查看结束画面点击  

**默认模板**：下一集或最佳相关 + 本系列列表 + 订阅。

**卡片（Cards）**：在中段关键时刻插入相关视频/列表/链接，服务于会话，而非打扰。注意频率。

**Shorts**：转化主路径是 Related Video，不是把结束画面思维硬套进 Shorts。【官方 Related 指南】

## 5. Studio 分析最小仪表盘

每周（冷启动）看：

| 模块 | 看什么 |
|------|--------|
| 内容 | 曝光、CTR（分来源）、观看时长 |
| 到达 | 流量来源结构 |
| 参与 | 留存关键时刻、结束画面 |
| 受众 | 是否逐渐形成稳定回访（后期再细） |

单视频诊断顺序：来源 → CTR → Intro → 全程曲线 → 是否值得 A/B 包装。

## 6. 如何读 Studio 分析（深度）

> 本节补齐「打开 Studio 后到底点哪里、数字什么意思」。路径名以桌面 Studio 常见结构为准；产品改名时以应用内文案为准。【官方】

### 6.1 先建立阅读顺序（单视频）

对任意一条长视频，按这个顺序读，避免被总播放带跑：

1. **到达 / Reach** → 流量来源结构  
2. **曝光与 CTR** → 分来源看（不要只看总 CTR）  
3. **参与 / Engagement** → Intro、留存曲线、平均观看时长/百分比  
4. **互动** → 结束画面、卡片（若有）  
5. **再决定动作**：改包装 / 改开场 / 改选题 / 什么都不改只攒样本

冷启动周会仍只盯三指标（来源、分来源 CTR、Intro），深度报告用于「出问题的那几条」。

### 6.2 曝光（Impressions）与 CTR【官方】

| 概念 | 含义 | 新手易错 |
|------|------|----------|
| **Impressions（曝光/印象）** | 缩图在 YouTube **站内**被计为「已展示」的次数 | 外链/嵌入带来的观看**不一定**产生印象 |
| **Impressions CTR** | 看到印象后点进观看的比例 | 用「总观看 ÷ 总曝光」手算往往对不上——不是所有观看都来自计费印象 |
| **Views from impressions** | 来自印象的观看 | 用来理解「包装漏斗」是否工作 |

**【官方】** 大约一半频道/视频的印象 CTR 落在 **2%–10%**；新片/低样本区间更宽。首页等大曝光表面 CTR **偏低很常见**；主要来自频道页的 CTR **偏高也常见**。应长期与自己历史比，并始终带上流量来源上下文。

**【官方 · 解码 CTR 与曝光】** 不同表面的观众意图不同：

- **搜索**：印象往往较少，但意图强 → CTR 常更高  
- **首页 / Browse**：印象多、竞争强、发现心态 → CTR 常更低  

因此：**禁止**把「搜索 CTR 12%」和「首页 CTR 3%」直接比出「首页挂了」的结论。

### 6.3 按来源拆 CTR（实操）

在视频级分析里打开流量来源 / 到达相关卡片，至少分清：

| 来源（常见名） | 你在诊断什么 | 健康时大致像什么（经验，非官方 KPI） |
|----------------|--------------|----------------------------------------|
| YouTube 搜索 | 标题/实体是否可被搜到、是否匹配意图 | CTR 相对高；观看目标明确 → 开场更忌自我介绍 |
| 浏览功能 / 首页等 | 包装是否在发现场景赢点击 | CTR 偏低正常；看是否「有曝光却点不动」 |
| 推荐的视频 / 相关 | 主题邻近与会话 | 内容是否像「看完 A 会想看 B」 |
| 播放列表 | 系列与会话设计 | 列表排序、片尾钩子是否工作 |
| Shorts | 短转长桥是否接通 | 有 Shorts 播放却零长视频来源 → 桥断了 |
| 外部 | 社区/社媒/嵌入 | 可喜但别当成站内推荐已通 |
| 直接或未知 | 书签、未登录、难识别 App | 样本噪声大，少做战略结论 |

**动作口诀**：

- 搜索 CTR 差 + 有搜索曝光 → 标题不够匹配查询词/意图  
- 浏览曝光高 + CTR 极低 → 重做封面**概念**  
- Shorts 来源接近 0 但你狂发 Shorts → Related/CTA/开头承接有断点  
- 外部很高、站内推荐弱 → 内容可能只在小圈子传，包装/品类匹配仍需练

### 6.4 留存曲线怎么读【官方 · Key moments】

打开「观众留存」报告（通常需一定观看量与时长；可能有 1–2 天延迟）：

| 形态 | 含义 | 优先动作 |
|------|------|----------|
| **Intro 低**（约前 30 秒掉很多） | 开场与包装预期不符，或无效片头 | 改开场或降承诺 |
| **早期陡降后平台** | 错的人点进来了，对的人留下了 | 检查包装是否吸引错受众 |
| **中段规律 Dip** | 注水、转场差、广告感口播 | 剪掉或提前剧透结构 |
| **Spike** | 重看/金句/爽点 | 做成 Shorts；或前移 |
| **结尾断崖后无回升** | 缺少结算或片尾太拖 | 提前给收获 + 清晰下一跳 |

**【行业实践】** 不要追求「完美水平线」；用曲线找**可剪的一段**，每次只修一类问题。

对照「曝光→点击→观看」漏斗：CTR 好而 Intro 崩 = 包装问题；CTR 与 Intro 都尚可但中段崩 = 结构/节奏问题。

### 6.5 流量来源结构（频道级）

频道分析 → 到达：看 28 天 / 90 天结构，问三句：

1. 是否逐渐出现**稳定搜索词**？（有 → 目录在积累资产）  
2. Browse / 相关是否在增长？（有 → 推荐匹配在改善）  
3. 是否过度依赖单一外部来源？（是 → 抗风险差）

**【神话】**「外部推流能永久启动算法。」  
**【纠正】** 外部可提供初始样本；持续分发仍取决于站内满意信号。【官方机制 + 行业实践】

### 6.6 新手 15 分钟诊断脚本（可打印）

```
视频标题：
日期范围：
1) 最大流量来源 = ____（占比 __%）
2) 该来源 CTR ≈ __%（对照：搜索偏高/首页偏低是否合理？）
3) Intro% ≈ __ ；是否低于自己近 10 条中位数？
4) 留存最大 Dip 发生在 __:__ ，内容是 ____
5) 本周唯一动作（只选一个）：
   [ ] 改封面概念  [ ] 改标题前半  [ ] 重剪开场
   [ ] 挂/改 Related  [ ] 什么都不改，再观察 __ 天
```

## 7. Made on YouTube 2026 工具地图

**【官方 Blog · 2026-09-23 前后】**

| 工具 | 用途 | 注意 |
|------|------|------|
| Ask Studio | 草稿反馈、标题缩图建议、分析解释 | AI 建议需人审；别盲目执行 |
| Insights / Research | 找异常好视频、启发下一题 | 异常值可能不可复现，找模式 |
| 标题/封面 A/B | 最多 3 变体；看 watch time | 见第 04、08 章 |
| Dynamic thumbnails | 多缩图智能展示 | 以账号可用性为准 |
| 视频剪辑 A/B | 多 hook 测试 | 「即将推出」——确认可用再写入流程 |
| Gemini 对话剪辑 | Shorts / Create 辅助 | 提效 ≠ 批量罐头 |
| AI 评论审核（测试/可选） | 学你的审核风格 | 需人工校准 |
| Likeness 保护 | 形象/声音相关检测 | 保护自己也被平台要求披露合成内容 |

**【官方 CEO】** AI 是表达工具不是替代；同时平台打击低质 AI slop。Studio AI 应用来自提升质量，不是降低独特性。

## 附录 · 发布前 Studio 点击路径（备忘）

**长视频发布检查**

1. 标题最终版（重要词靠前）  
2. 自定义缩图已传（≥1280×720）  
3. 播放列表已加入对应桶  
4. 结束画面模板已套  
5. 卡片（若用）已打在价值点而非随意分钟  
6. 是否 Made for Kids 选择正确  
7. 是否需要合成内容披露  
8. 定时：对齐观众在线窗口  

**Shorts 发布检查**

1. 独立价值成立  
2. Related Video 已选且意图匹配  
3. 末 5 秒 CTA 已拍进片子（不要指望后期口头补救却忘了指）  
4. 字幕大、前 1 秒进冲突  
5. 原创/授权自检  

**频道页季度检修**

- 预告片是否仍代表当前最好内容？  
- 「从这里开始」是否换成了真正代表作？  
- 死链播放列表、空分区是否清理？
