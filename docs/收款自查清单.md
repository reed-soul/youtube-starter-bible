# YouTube 收款自查清单（可勾选、可打印）

> 相关：[付款日历 / 到账推算](youtube-付款日历.md) · [AdSense 电汇收款](adsense-电汇收款.md) · [W-8BEN 图解](w8ben-填写图解.md) · [13 §4 收款](13-中国大陆创作者专章.md#_4-adsense-收款-电汇、银行与结汇)

## 一句话答案

**【官方】** 钱要到账，必须依次满足：YPP 通过并关联 AdSense YouTube 广告账号 → 身份与地址（PIN）验证 → 美国税务信息**已批准** → 添加收款方式（中国收款地址：**电汇**或 **Hyperwallet**）→ 每月 **20 日**余额 ≥ **$100** 且无暂停 → **21–26 日**发起付款 → 电汇最多约 **15 个工作日**入账（[14732067](https://support.google.com/youtube/answer/14732067?hl=zh-Hans) · [7164703](https://support.google.com/adsense/answer/7164703?hl=zh-Hans) · [1709871](https://support.google.com/adsense/answer/1709871?hl=zh-Hans) · [1714397](https://support.google.com/adsense/answer/1714397?hl=zh-Hans)）。

## 每一项为什么重要

| 项目 | 官方口径 | 常见卡点 |
|------|----------|----------|
| YPP + AFY 关联 | 只能在 YouTube 工作室中新建 AdSense YouTube 广告账号 | 地区资格 ≠ 收款地址国家 → [YPP 地区资格](ypp-中国大陆资格.md) |
| PIN | 通常约 3 周；满 3 周可重寄；生成日起 4 个月内完成；Google 不提供运单号 | 地址写法与身份资料不一致 |
| 税务信息 | 未提交：个人全球最高约 24% 预扣 | 名字与付款资料不符 → 进入审核 → [W-8BEN 图解](w8ben-填写图解.md) |
| 收款方式 | 中国收款地址：电汇、Hyperwallet 适用；银行须与收款地址同国 | SWIFT 无法保存往往是国家不一致 |
| 门槛与截止 | USD：验证 $10、选方式 $10、起付 $100；20 日前改完信息 | 20 日后修改顺延到下个周期 |
| 付款与入账 | 21–26 日发起；电汇最多约 15 个工作日 | 中间行可能扣费；本行审核时间不一 |
| 结汇 | SAFE：便利化额度 5 万美元/人·年（非硬上限）；超额凭真实性材料 | 材料类型见细则第十条；**以开户行要求为准**，本站不写用途代码 |
