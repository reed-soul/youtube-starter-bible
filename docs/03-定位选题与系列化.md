## 5分钟速读

> 先扫这几条再往下精读；细节与证据等级见正文。

- 定位三角：观众处境 · 承诺结果/感觉 · 明确排除。
- 内容桶（Buckets）> 死板季播：单集可独立看，列表提供「想继续」。
- 选题漏斗：灵感 → 谁会点 → ≥8 标题+≥3 封面概念 → 能兑现 → 进桶。
- 搜索型（清楚描述）与浏览型（激发好奇）包装不同；健康指标也不同。
- 搜索研究：吃自动补全自然语言短语，写进标题前半。
- 播放列表要有「从这里开始」；编号别抢标题前缀。

## 1. 定位三角：观众 · 承诺 · 排除

完整定位至少回答：

1. **观众**：ta 处在什么处境？（语言、地域、技能阶段、兴趣密度）  
2. **承诺**：看完一条/订阅一个月后，稳定得到什么结果或感觉？  
3. **排除**：你明确不做哪些（避免吸引力散射）？

把三角写进 About 第一屏、频道预告片、置顶评论模板。冷启动期**宁可窄**；变宽是有核心粉之后的事。

**【官方灵感】** 即使在细分领域，也可用更普世的问题作「入口标题」，再在内容里给深度——这是扩大吸引面，不是放弃定位。

---

## 2. 内容桶（Buckets）优于死板季播

**【行业实践】** 机械的「第 1/2/3 集必须按序看」在 YouTube 上常常不利：推荐与浏览场景充满随机进入。更稳的是 **内容桶**：

- 桶内风格、结构、预期一致  
- 单集尽量**可独立观看**  
- 用播放列表与片尾钩子提供「想继续」的路径，而不是惩罚跳进者

示例桶：

| 品类 | 桶 A | 桶 B | 桶 C |
|------|------|------|------|
| 科技 | 开箱 10 分钟 | 深度拆解 20 分钟 | 一周资讯短评 |
| 教育 | 概念入门 | 错题/误区 | 完整项目跟做 |
| 生活 | 清单避坑 | 一天跟拍 | 问答 |
| 叙事 | 人物故事 | 事件复盘 | 读者来信解读 |

目标：陌生人刷到任意一集仍能说「哦，这是那个做 X 的频道」。

## 3. 选题漏斗：从想到可拍

```
灵感便签
  → 能否用一句话说清「谁会点」？
  → 能否写出 ≥8 个标题变体 + ≥3 个封面概念？【行业实践：包装前置】
  → 你是否有权/有能力兑现（素材、知识、授权、伦理）？
  → 能否归入某内容桶？能否剪 2+ Shorts？
  → 进入「本月拍摄池」
```

砍题要狠：不能包装的想法，对 YouTube 而言成本往往高于「少一条」。

维护表格列：主题、桶、搜索/浏览、标题草案、封面概念、预估难度、状态。

## 4. 搜索型 vs 浏览型

| | 搜索型 | 浏览型 |
|---|--------|--------|
| 观众心态 | 带着问题来 | 被封面打断 |
| 标题倾向 | 清楚描述【官方】 | 激发好奇【官方】 |
| 开场 | 尽快给答案方向 | 尽快给冲突/反差 |
| 风险 | 太干、像说明书 | 好奇过度变标题党 |
| 冷启动价值 | 可累积长尾 | 可爆发但难预测 |

健康目录通常**两者都有**：搜索型做基本盘，浏览型做扩展。纯搜索可能增长慢；纯浏览可能波动大且品牌感弱。

## 5. 搜索驱动的选题研究（实操）

冷启动最稳的「可被发现」路径之一，是让标题与内容对齐**真实搜索问法**。【官方】搜索型标题应清楚描述内容；重要词靠前。本节把「打开搜索框」变成可重复作业。

### 5.1 30 分钟搜索研究流程

1. **种子词**：从定位句抽出 5–10 个核心实体/问题（例：`美国租房押金`、`Homebrew 换源`、`离职证明`）。  
2. **YouTube 搜索联想**：每个种子词打进 YouTube 搜索框，**不要按回车**，先抄下自动补全 5–10 条自然语言短语。  
3. **结果页扫读**：再按回车，看前 10–20 条：标题句式、时长、是否有「2025/2026」、封面是否清晰承诺。  
4. **缺口标注**：标出「有搜索需求但前排答案旧/浅/语言不对」的空位——这是你的机会，不是去抄爆款皮囊。  
5. **写入选题池**：每条候选必须同时有：可搜短语、一句话谁会点、能否写出 ≥8 标题变体。

### 5.2 标题怎么「吃」搜索词（且不像关键词墙）

| 做法 | 示例 |
|------|------|
| ✅ 完整短语靠前 | 「美国租房押金怎么退：留学生第一次踩的 5 个坑」 |
| ✅ 实体 + 结果 | 「Homebrew 换源失败？10 分钟修好常见 3 类报错」 |
| ❌ 关键词堆 | 「租房 押金 美国 留学生 退钱 攻略 2026 必看」 |

**【官方】** 搜索意图强时，观众带着问题来——开场应尽快给答案方向，而不是品牌片头。

### 5.3 用 Studio 反推「已验证搜索」

当你已有视频：

1. 视频分析 → 到达 → **YouTube 搜索** 卡片，记下真实带量词。  
2. 把高转化词升格为「系列母题」或下一集标题前半。  
3. 低曝光高 CTR 的搜索词：可能值得做更深的「完整版」。  
4. 有曝光无点击的搜索展示：标题与查询意图不匹配——改标题前半，而非先怪算法。

### 5.4 搜索研究的边界

- 工具商「搜索量分数」是【行业实践】辅助，**以 Studio 真实来源为准**。  
- 纯追热词会漂移定位；每个热词仍要过定位三角与包装门禁。  
- 浏览型爆款可以穿插，但搜索型目录是冷启动的抗风险资产。  
- 中文创作者：华语查询与英语查询是不同市场；不要用中英混排同时讨好两边。

## 6. 系列与播放列表信息架构

建议最少四类列表：

1. **旗舰系列 / 核心桶**（首页置顶）  
2. **从这里开始**（3–5 条代表作，给新访客）  
3. **最新长视频**（或系统自动，视 Studio 布局）  
4. **Shorts 精选**（可选）

原则：

- 单集标题自洽；系列名可用播放列表名 + 片尾口播强化  
- 系列编号放标题**后部**，避免占用前半注意力【与官方「重要词靠前」一致】  
- 软连续：片尾预告下一集，但不把理解本集所需的关键信息只藏在上集  

Home 布局细节见 [07](07-频道装修与Studio.md)。

## 7. Podcast 功能（适合口述长内容）

**【官方】** 在 YouTube 上，播客 = 带播客功能的播放列表；剧集 = 列表中的视频。应放入完整剧集，并按消费顺序排列。

要点摘要：

- Studio 可新建播客或为现有列表添加播客功能  
- 方形封面常见建议尺寸 **1280×1280**  
- 标题避免空洞（如只写「完整集」「Podcast」）  
- 连续剧：旧→新；单元剧：常新→旧（按官方说明选择）  
- 不要把 Shorts 宣传片塞进播客列表（Shorts 不会按音乐播客那套进 YouTube Music）  
- 可能获得 Music 背景播放、播客标识、播客相关发现等能力（以当前产品为准）

若你的频道是「可听」的教学/访谈/故事，值得在有 5+ 集后开启。

## 8. 跨品类选题公式

可直接填空（写 8–12 个变体再选）：

1. **错误信念**：「大家都以为 X，其实 Y」  
2. **对比**：「A vs B：哪个适合【某人】」  
3. **清单**：「【年】做【事】前必须知道的 N 件事」  
4. **过程**：「我如何在 N 天完成 X（含失败）」  
5. **拆解**：「【热门对象】底层到底怎么运作」  
6. **时间盒**：「只用【预算/时间】挑战 X」  
7. **身份入口**：「写给【初学者/转行者/父母】的 X」  
8. **后果**：「忽视 X 的真实代价」  

**【官方】** 用更贴近日常生活的问题作入口，再提供专业深度——有利于扩大 Appeal。

## 9. 叙事/悬疑示例（可选）

若你做故事类，可把「未闭合好奇」当作浏览型包装工具，但必须：

- 开场兑现封面承诺【官方】  
- 单集可独立看  
- 真实案件：可核、不骚扰当事人、虚构则标明  

叙事标题方向示例（通用故事，非某一频道）：反差身份、时间压力、被忽略的文件、唯一视角、物件线索等——详细包装见下一章。
