## 5分钟速读

> 先扫这几条再往下精读；细节与证据等级见正文。

- 先用第 10 章定位断点，再对号入座；一次只纠正一个主模式。
- 数据类：高 CTR 低留存（骗点）、有曝光点不动、搜索零、会话断。
- 产品类：假系列、赛道漂移、包装门禁缺失、伪进度忙碌。
- Shorts 类：空播放、刮擦搬运、受众错配。
- 节奏/健康：燃尽日更、消失式停更；先降频熔断。
- 合规：买量互粉、无授权、伦理翻车——增长手段里直接删除。

## 2. 分发与数据类失败

### 2.1 高 CTR + 低留存（骗点螺旋）

| | |
|--|--|
| **症状** | 印象 CTR 漂亮；Intro/AVD 差；曝光先涨后缩或「不如预期」。 |
| **机制** | 【官方】误导性包装抬高 CTR，但平均观看时长差 → 更难被推荐。 |
| **纠正** | 降承诺或改开场兑现；A/B 以 watch time 为准，勿只追 CTR；删掉封面里兑现不了的字。 |
| **回看** | [01](01-推荐系统心智模型.md) · [04](04-标题封面与包装.md) · [05](05-脚本留存与完播.md) |

### 2.2 曝光尚可 + CTR 极低（包装失明）

| | |
|--|--|
| **症状** | 有曝光机会，但几乎无人点；频道页 CTR 尚可、首页 CTR 极差。 |
| **机制** | 浏览场景竞争强；缩图一瞥不可读或承诺模糊。【官方】首页 CTR 偏低常见，但「极低且长期」仍是包装问题。 |
| **纠正** | 重做**概念**（不是微调饱和度）；标题前半放实体/结果；手机小图冷测。 |
| **回看** | [04](04-标题封面与包装.md) · [07](07-频道装修与Studio.md) 分析节 |

### 2.3 只看总播放、不看来源（错误仪表盘）

| | |
|--|--|
| **症状** | 「这条 2 万播放很成功」——其实 80% 来自一次外部转发，站内推荐几乎为零。 |
| **机制** | 外部流量不自动等于推荐健康；【官方】CTR/曝光主要描述站内印象路径。 |
| **纠正** | 周复盘强制看：搜索 / Browse·首页 / 相关 / Shorts / External 占比；分来源看 CTR。 |
| **回看** | [07](07-频道装修与Studio.md) · [02](02-冷启动0到1000.md) |

### 2.4 「删除重传洗推荐」迷信

| | |
|--|--|
| **症状** | 同一内容反复删发，指望重置算法。 |
| **机制** | 【神话】无官方「洗推荐」功能；浪费 SEO 与外链，还可能像垃圾行为。 |
| **纠正** | 改包装、改开场、改选题；旧片回炉缩图。【官方】允许更新旧缩图。 |

## 3. 内容与产品类失败

### 3.1 假系列（编号连续，体验不连续）

| | |
|--|--|
| **症状** | 标题写「第 7 集」，但第 1–6 集风格乱跳；新观众跳进第 7 集完全懵。 |
| **机制** | YouTube 充满随机进入；【行业实践】硬季播惩罚跳进者。 |
| **纠正** | 内容桶 + 单集可独立看；编号靠后；播放列表承担「顺序」。 |
| **回看** | [03](03-定位选题与系列化.md) |

### 3.2 赛道漂移（每天一个新品类）

| | |
|--|--|
| **症状** | 上周评测、本周美食、下周情感鸡汤；订阅后「不知道下次会看到什么」。 |
| **机制** | 推荐难以形成稳定「视频×观众」匹配；会话难连播。 |
| **纠正** | 回到定位三角；20 条内选题必须指向定位句。 |
| **回看** | [02](02-冷启动0到1000.md) · [03](03-定位选题与系列化.md) |

### 3.3 搜索词堆砌标题（SEO 幻觉）

| | |
|--|--|
| **症状** | 标题像关键词墙；自然搜索 CTR 反而差；品牌感零。 |
| **机制** | 【官方】搜索型标题应清楚描述；自然语言完整短语优于堆词；标签非发现核心。 |
| **纠正** | 用搜索联想找**真实问法**；标题写成完整可读句；描述里再补长尾。 |
| **回看** | [03](03-定位选题与系列化.md) 搜索研究节 · [04](04-标题封面与包装.md) |

### 3.4 「电影感」优先于听清看懂

| | |
|--|--|
| **症状** | 调色很美，对白听不清；字幕糊成一团。 |
| **机制** | Engagement 先死在听不清；Satisfaction 无从谈起。 |
| **纠正** | 收音与字幕下限 > 空有设备；冷启动用「可发布的清晰」标准。 |

## 4. Shorts 与发现类失败

### 4.1 刮擦搬运 / 无实质聚合 Shorts

| | |
|--|--|
| **症状** | 别人视频 + 轻微滤镜/调速/模板字幕；一度有播放，2026 后分发骤降。 |
| **机制** | 【官方表述 · 约 2026-10-01】Shorts 推荐进一步优先原创，降低无实质改动的再上传触达；并与垃圾政策精神一致。 |
| **纠正** | 自己拍、自己长视频切片、或显著解说/叙事价值；停止「聚合农场」路线。 |
| **回看** | [06](06-Shorts漏斗.md) · [09](09-变现与合规红线.md) |

### 4.2 Shorts 空播放（有触达无转化）

| | |
|--|--|
| **症状** | Shorts 百万级，订阅不动，长视频来源里几乎无 Shorts。 |
| **机制** | 受众分层：大量 Shorts-Only；无 Related / 无 CTA / 长视频开头不接。【官方 Related 指南】 |
| **纠正** | 走完官方四步；检查 Short 选题是否落在你的内容桶。 |

### 4.3 「完整版在主页」无独立价值 Short

| | |
|--|--|
| **症状** | Short 只有「想看完整版去主页」；信息流里立刻划走。 |
| **机制** | 【官方】从长视频剪出的 Short 也须独立成立。 |
| **纠正** | 先给一个完整小收获或强钩子，再 CTA。 |

### 4.4 只做 Shorts、零长视频目录

| | |
|--|--|
| **症状** | 触达大，搜索与品牌资产弱；变现与合作议价难。 |
| **机制** | Shorts 与长视频是不同情境；2026 原创/质量压力更大。 |
| **纠正** | 至少恢复可预测长视频；用 Shorts 做发现与桥。 |

## 5. 节奏与创作者健康

### 5.1 燃尽式日更（Burnout Daily Upload）

| | |
|--|--|
| **症状** | 坚持日更 3 周 → 消失 3 个月；质量断崖；观众流失。 |
| **机制** | 【行业实践】系统不直接发「更新奖」；劣质多更伤害会话；创作者不可持续 = 频道不可持续。 |
| **纠正** | 可预测的周更/双周更；设「燃尽熔断」（连续两周完不成 → 立刻降频）。 |
| **回看** | [08](08-发布节奏实验与复盘.md) |

### 5.2 装修强迫症（零上传优化）

| | |
|--|--|
| **症状** | 横幅换 20 版，视频 0 条。 |
| **纠正** | 先发 5 条代表作再精修装修。【行业实践】 |

### 5.3 完美主义瘫痪

| | |
|--|--|
| **症状** | 脚本改三个月仍不上线。 |
| **纠正** | 定义「可发布的丑」：听清、看清、兑现承诺；用发布后数据迭代。 |

### 5.4 数据焦虑（每小时刷分析）

| | |
|--|--|
| **症状** | 发布 2 小时就因 CTR 波动改标题三次，打断 A/B。 |
| **纠正** | 冷启动改为**每周**三指标复盘；测试中途不手改。【官方】中途改包装会中断 A/B。 |

## 6. 合规与伦理翻车

### 6.1 买量 / 互粉 / 刷评

| | |
|--|--|
| **症状** | 粉涨播放假；随后处罚或推荐质量崩。 |
| **机制** | 【官方】虚假互动明确禁止；虚假流量不计。 |
| **纠正** | 立刻停止；删除相关外链与置顶；走合法助推（见第 02/09 章）。 |

### 6.2 标题党擦边 + 不适操控

| | |
|--|--|
| **症状** | 惊吓封面、色情擦边、与内容严重不符。 |
| **机制** | 【官方】误导影响推荐；2026 质量/不适内容与变现风险上升。 |
| **纠正** | 包装必须可兑现；敏感题材走伦理清单（第 09 章）。 |

### 6.3 真实故事「猎奇无底线」

| | |
|--|--|
| **症状** | 未核实谣言、骚扰当事人、暴露未成年人、把悲剧当娱乐。 |
| **机制** | 平台政策 + 当地法律 + 声誉风险；本指南**非法律意见**，但伦理底线是增长前提。 |
| **纠正** | 事实可核、虚构标明、保护受害者与未成年人；不确定则不做。 |

### 6.4 AI 罐头农场

| | |
|--|--|
| **症状** | 日更同质 AI 口播/模板片；进 YPP 困难或事后不稳。 |
| **机制** | 【官方 CEO】管理 AI slop；变现政策澄清重复模板化等风险。 |
| **纠正** | AI 提效可以，量产无差异不行；每条要有可识别的原创观点或体验。 |

## 7. 「看起来很努力」的伪进度

这些活动消耗时间，但很少改善漏斗：

| 伪进度 | 更好替代 |
|--------|----------|
| 研究「下一次算法更新内幕」3 小时 | 改一条视频的开场并记录 Intro |
| 买第 5 个提词器支架 | 完成选题池 30 个 + 包装门禁 |
| 跟风抄 10 个爆款标题皮囊 | 用搜索研究写出可兑现的自己的题 |
| 同时开 4 个赛道测试「哪个火」 | 单桶做透 15 条再扩展 |
| 评论区互赞群 | 【官方】禁止路径；改为有价值回复 |

**【神话】**「努力程度与推荐成正比。」  
**【纠正】** 系统响应的是观众满意信号；努力必须落在曝光→点击→留存→满意链路上。
