## 1. 推荐漏斗（曝光 → 满意）

详见 [01 · 创作者侧四段漏斗](01-推荐系统心智模型.md)。

```mermaid
flowchart LR
  A["曝光<br/>Impressions"] --> B["点击<br/>CTR"]
  B --> C["留存<br/>Engagement / AVD·AVP"]
  C --> D["满意<br/>Satisfaction"]
  D -.->|正向信号| A
```

**配套官方三桶**：Appeal（吸引）→ Engagement（粘住）→ Satisfaction（满意）。

## 2. 留存曲线标注概念

详见 [05 · Studio 关键时刻](05-脚本留存与完播.md)。

```mermaid
flowchart TB
  subgraph curve ["留存曲线读法（概念）"]
    I["Intro ≈ 前30秒<br/>开场是否匹配预期"]
    F["平坦段<br/>几乎无人离开 → 可前移"]
    S["Spike 尖峰<br/>重看/分享 → 剪 Shorts 或前移"]
    D["Dip 低谷<br/>跳过/离开 → 删剪加速"]
  end
  I --> F
  F --> S
  F --> D
```

**诊断口诀**：CTR 好 · Intro 崩 → 包装/开场；Intro 尚可 · Dip 密 → 结构/密度。
