## 1. 如何使用本清单

1. 选最近 **10 条长视频 + 10 条 Shorts**（不足则全选）  
2. 打开 Studio 近 28/90 天  
3. 逐项勾选；每项只能答：**是 / 否 / 不适用**（打印版可手写 ☑ / ☐ / —）  
4. 所有「否」收到「本周只修 1–3 件」列表  
5. 两周后复测同一项，避免幻觉进步  

证据不够时，标「数据不足」，不要脑补算法阴谋。

## A. 定位与目录

- [ ] 一句话品类让陌生人 5 秒看懂  
- [ ] 最近 10 条长视频像「同一频道」  
- [ ] 存在 2–4 个清晰内容桶  
- [ ] 有「从这里开始」播放列表（3–5 条）  
- [ ] 单集大多可独立看懂  
- [ ] About 第一句与视频实际一致  
- [ ] 明确排除项写得出来（你不做什么）

## B. 包装

- [ ] 每条长视频都有自定义封面  
- [ ] 封面一瞥可读；大字少；不与标题复读  
- [ ] 标题重要信息靠前；系列号靠后  
- [ ] 抽 5 条：标题承诺在前 30 秒兑现  
- [ ] 每条新片有标题多草案记录（或等效流程）

## C. Studio 分析

- [ ] CTR 按来源解读（首页 vs 频道页 vs 搜索 vs Shorts）  
- [ ] 能解释「搜索 CTR 高、首页 CTR 低」不一定是故障  
- [ ] 能指出是否存在「高 CTR + 低 AVD」危险片  
- [ ] Intro% 有基线；能指出开场最差片  
- [ ] 留存 dips / spikes 曾被用来剪片或衍生 Shorts  
- [ ] 流量来源中搜索/浏览/相关/Shorts/外部结构可知  
- [ ] 不会只因「总曝光低」就同时改五个变量  
- [ ] 单视频诊断遵循：来源 → CTR → Intro → 曲线 → 唯一动作  

**否 →** [01](01-推荐系统心智模型.md) [05](05-脚本留存与完播.md) [08](08-发布节奏实验与复盘.md)

## 一页作战卡

1. 选题：不能写出可点击标题+封面概念 → 不做  
2. 包装：多草案；一瞥测试；承诺可兑现  
3. 开场：15 秒内进入价值；无无效问候  
4. 中段：每分钟一增量；Dip 必处理  
5. 片尾：收获 + 下一跳 + 结束画面  
6. Shorts：独立价值 → Related → 长视频接住  
7. 节奏：可维持；单变量实验  
8. 工具：Studio A/B 看 watch time  
9. 红线：不买量、不互粉、不骗点、不空洞搬运  
10. 目标：先让对的观众满意，再扩张  

完整可打印版见 **[作战卡.md](作战卡.md)**（漏斗 · 包装 · 留存钩子 · Shorts 桥 · 节奏 · 红线）。建议与本页记分表一起打印，贴在显示器旁边。失败模式对号入座见 [12](12-反例与失败模式.md)；图示见 [图示.md](图示.md)。
