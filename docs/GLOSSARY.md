# 术语表 GLOSSARY

> 中英对照，便于阅读 Studio 界面与官方文档。定义尽量贴近【官方】用语；括号内为创作者口语。

---

## A–C

**A/B Testing（标题/封面测试）**  
在 YouTube Studio 中对最多三个标题、缩图或组合进行实验；胜出通常按观看时长份额。【官方】

**Advanced features（高级功能）**  
频道解锁的一系列能力门槛（常与验证/历史相关）；A/B、部分功能可能依赖它。【官方】

**Advertiser-friendly（广告适切）**  
内容是否适合展示广告的指南；不适切可能导致少广告或无广告，不等于社区违规下架。【官方】

**Appeal（吸引）**  
推荐相关信号桶之一：人们是否选择观看，或忽略/不感兴趣。【官方】

**AVD / Average View Duration（平均观看时长）**  
观众平均看了多久。常与 CTR 对照诊断「骗点」。

**AVP / Average Percentage Viewed（平均观看百分比）**  
平均看了视频的百分之多少。

**Bucket / 内容桶**  
同一频道内风格一致、可独立观看的主题分组。【行业实践用语】

**Card（卡片）**  
视频播放中弹出的信息点，可链到视频/列表/链接等。【官方产品】

**Click-Through Rate / CTR（印象点击率）**  
曝光被点击的比例。须分来源看；官方提醒勿用误导抬 CTR 却损观看时长。【官方】

**Community Guidelines（社区准则）**  
平台行为与内容底线；违规可致删除警告（strike）乃至终止。【官方】

**Content ID**  
版权管理系统；匹配到权利方素材时可禁播、创收（收入可能归权利方）或跟踪。【官方】不等于版权警示。详解 → [版权主张与警示](youtube-版权主张与警示.md)。

**版权警示（Copyright strike）**  
因有效的版权内容移除要求产生；学完版权学院后 90 天失效；90 天内 3 条可能终止。【官方】

**社区准则警示（Community Guidelines strike）**  
违反社区准则时产生；首次通常为警告；第 1 / 2 条警示限制上传或发布 1 / 2 周。【官方】

**品牌账号（Brand Account）**  
可与 YouTube 频道关联、允许多人管理的账号类型；2021-08-04 后新建的只能关联 YouTube。【官方】→ [注册与品牌账号](youtube-注册与品牌账号.md)。

**W-8BEN**  
美国境外个人受益所有人常用的美国税务信息表；可用来申请税收条约优惠。【官方】→ [W-8BEN 图解](w8ben-填写图解.md)。

## D–I

**Dynamic thumbnails（动态缩图）**  
向不同观众段展示更可能吸引其点击的缩图选项（2026 Studio 能力方向）。【官方 Blog】

**End screen（结束画面）**  
片尾可点击元素区（视频、列表、订阅等）。【官方】

**Engaged views（参与观看）**  
Shorts 等场景下，Studio 可能提供的、与「开始即计观看」相区别的指标名；以当前界面说明为准。【产品可能迭代】

**Engagement（粘住）**  
信号桶：开始看后是否留下来。【官方】

**Fake engagement（虚假互动）**  
买量、互粉、强迫观看等；明确禁止。【官方】

**Home / 首页**  
个性化推荐主表面之一；登录后主要依赖观看历史等。【官方】

**Impressions（曝光/印象）**  
缩图被展示的次数（定义以 Studio 说明为准）。

**Intro（开场留存）**  
关键时刻报告中，约前 30 秒仍在看的比例。【官方】

**Dip / Spike（留存低谷 / 尖峰）**  
留存曲线上的异常离开点与重看点；用于剪辑与 Shorts 选题。【官方 Key moments】

## L–R

**Likeness detection（形象检测）**  
帮助创作者管理其形象在 AI 生成内容中被使用的工具方向。【官方】

**Long-form（长视频）**  
相对 Shorts 的传统横/竖较长内容（口语）；政策里常与 Shorts 分列门槛。

**Made for Kids**  
面向儿童的设定；影响数据与变现功能。【官方】

**Metadata（元数据）**  
标题、缩图、描述、标签等。【官方】强调前三者对发现更重要。

**Podcast（YouTube 播客功能）**  
带播客功能的播放列表；剧集为其中视频。【官方】

**Related video（相关视频链接 · Shorts）**  
在 Short 上挂接到同频道另一视频/直播的可点击链接，用于短转长。【官方 Blog 2026-07】  
**勿与**流量来源里的「相关视频 / Suggested」混淆：后者是观众从其他视频侧栏/下一条过来的来源类型。【官方 Analytics】

**RPM（Revenue per mille）**  
**【官方】** 分成之后每 1,000 次观看的收入（含广告、会员、Premium、超级留言等）；分母含全部观看。【官方】[9314357](https://support.google.com/youtube/answer/9314357?hl=en)。受地区、题材、适切、季节影响，不可跨频道硬比。估算 → [1 万播放多少钱](youtube-1万播放多少钱.md)。

**CPM（Cost per mille）**  
**【官方】** 广告主为 1,000 次广告展示付的钱，分成前；另有「基于播放的 CPM」。官方例子与 RPM 对照 → [1 万播放多少钱](youtube-1万播放多少钱.md)。

## S–Y

**Satisfaction（满意）**  
信号桶：是否觉得值得；含问卷等。【官方】

**Shorts**  
短视频形态与信息流产品；有独立推荐与变现计数逻辑。【官方】

**Spam（垃圾内容政策）**  
含欺骗性做法、无关推广、部分再利用等。【官方】

**Strike（删除警告）**  
社区准则违规累积；影响功能与 YPP。【官方】

**Sub4Sub（互粉互订）**  
虚假互动的一种，禁止。【官方】

**Traffic source（流量来源）**  
观众如何找到内容：搜索、浏览/首页、相关、播放列表、Shorts、外部等。【官方 Analytics】须分来源读 CTR。

**Trailer（频道预告片）**  
给未订阅访客的频道页视频。【官方】

**Up Next（下一条）**  
当前视频之后的建议；主要信号是当前视频。【官方】

**Watch time（观看时长）**  
累计被观看的时间；YPP 合格小时有定义过滤。A/B 胜出常用 watch time share。【官方】

**YPP / YouTube Partner Program（合作伙伴计划）**  
官方变现计划；含门槛、审核与持续合规。【官方】

**AI slop**  
口语：低质、重复、空洞的 AI 量产内容。CEO 2026 公开信将其列为需管理对象。【官方用语出现在公开信】

## 本指南补充（Phase 2 统一）


**Browse / 浏览功能**  
Studio 流量来源之一，常含首页等发现表面；与「搜索」意图不同，CTR 基线也不同。【官方 Analytics】

**CTA（Call to Action · 行动号召）**  
明确请观众做的下一步：点 Related、看完整集、订阅、进列表等。Shorts 末 5 秒强 CTA 为官方转化法一环。

**Glance test / 一瞥测试**  
手机缩小缩图，0.5–1 秒内能否看懂冲突或结果承诺。【行业实践】

**钩子 / Hook**  
开场或结构中的滞留装置（开放循环、倒计时、问题句等）；须服务 Satisfaction，而非纯操纵。【官方谈片头钩子 + 行业实践工具箱】

**漏斗 / Funnel（创作者侧）**  
曝光 → 点击 CTR → 留存 → 满意的诊断链；与官方三桶 Appeal / Engagement / Satisfaction 对应。【本指南用语】

**包装 / Packaging**  
标题 + 缩图（及彼此关系）对点击的共同作用；「封面概念」指缩图创意方向。【行业实践】

**搜索型 / 浏览型（选题与标题）**  
搜索型：清楚描述，服务带着问题来的观众；浏览型：激发好奇，服务发现场景。健康 CTR/留存形态不同。【官方标题分类 + 本指南】

**缩图 / Thumbnail（自定义缩图）**  
视频在各表面展示的图片；官方口中的 thumbnail。口语「封面」多指同一物或「标题+缩图」包装整体——本指南正文优先用**缩图**指产品对象，用**封面概念**指创意草图。【官方】

**完播 / 完播率（口语）**  
常指看完全片或很高的平均观看百分比（AVP）。专家诊断优先看留存曲线与 Intro/Dip/Spike，而非单一完播数字。

**骗点**  
包装承诺显著高于内容兑现，典型数据：高 CTR + 低 AVD/崩 Intro；官方指出更难被推荐。

## 中文创作者常用口语

| 口语 | 含义 |
|------|------|
| 爆款 | 相对自己基线异常高表现的单集；不可当战略唯一 |
| 投流 | 常指站外买量；平台内有官方推广产品，勿与违规刷量混淆 |
| 切片 | 从长视频裁 Shorts |
| 钩子 | 开场或结构中的滞留装置（正式释义见上「钩子 / Hook」） |
| 人设 | 稳定的表达身份；不等于虚构欺诈 |
| 垂直 | 窄定位 |
| 数据好看 | 常只看播放；专家看来源+CTR+留存+满意 |
| 封面 | 口语常＝自定义缩图；写作时与「缩图」对齐，创意阶段称「封面概念」 |
| 完播 | 口语＝高 AVP / 看完；诊断请回到留存曲线 |
| 骗点 | 高 CTR 低兑现；见上「骗点」 |
| 空播放 | Shorts 触达高但无订阅/长视频转化（桥断） |
| 日更燃尽 | 不可维持的过高频率导致质量与身心双崩 |
