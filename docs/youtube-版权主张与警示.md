# YouTube 版权主张、版权警示、社区准则警示有什么区别？

> 相关：[09 版权与再利用](09-变现与合规红线.md) · [YPP 审核与再利用自查](ypp-审核被拒与申诉.md#再利用内容自查表) · [13 §7 搬运与原创](13-中国大陆创作者专章.md#_7-搬运、二次利用与-shorts-原创) · [注册与权限](youtube-注册与品牌账号.md)

## 一句话答案

**【官方】** **Content ID 版权主张**是系统自动匹配，后果可能是禁播、对方创收或跟踪，但**不算警示**；**版权警示**来自版权方提交的有效法律移除要求，学完版权学院后 **90 天**失效，**90 天内 3 条**可能被终止；**社区准则警示**来自违反社区准则，首次通常只是警告，第 1 条警示**1 周**、第 2 条**2 周**不能发布，**90 天内 3 条**可能被永久移除（[6013276](https://support.google.com/youtube/answer/6013276?hl=zh-Hans) · [2814000](https://support.google.com/youtube/answer/2814000?hl=zh-Hans) · [2802032](https://support.google.com/youtube/answer/2802032?hl=zh-Hans)）。

## 收到通知后先判断是哪一种

1. **看 YouTube 工作室 → 内容 → 「限制」列**：显示「版权主张」= Content ID；显示「版权 - 移除」= 版权内容移除要求（会带来版权警示）（[6013276](https://support.google.com/youtube/answer/6013276?hl=zh-Hans)）。  
2. **看邮件发件人**：官方版权警示通知来自 `no-reply@youtube.com`（[2814000](https://support.google.com/youtube/answer/2814000?hl=zh-Hans)）。  
3. **社区准则**问题会写明违反了哪条政策、对频道有何影响（[2802032](https://support.google.com/youtube/answer/2802032?hl=zh-Hans)）。

## Content ID 版权主张：异议与申诉

**【官方】**（[2797454](https://support.google.com/youtube/answer/2797454?hl=zh-Hans) · [6013276](https://support.google.com/youtube/answer/6013276?hl=zh-Hans)）

- 版权主张会影响视频，**一般不会影响频道或账号**；也**不会**因为视频有有效主张而收到版权警示。  
- 只有确信自己拥有全部必要权利（或属于合理使用等例外）才提出异议。官方列明以下**不是**正当理由：注明了版权所有者；拥有相应视频或歌曲的副本；选择不通过该视频创收。  
- 提出异议后，主张方有 **30 天**回应：撤销 / 恢复主张 / 不回应则主张失效。  
- 异议被拒可申诉，主张方有 **7 天**回应；对**禁播**类主张可直接「升级为申诉」，跳过 30 天阶段。  
- 异议**一旦提交无法取消**；反复或恶意滥用异议流程可能导致处罚。  
- 异议处理期间，主张方随时可能改交版权内容移除要求；若有效，视频被移除，频道收到**版权警示**。

不确定时，YouTube 原文建议提出异议前寻求法律建议。本站不做法律判断。

## 版权警示：三种解除方式

**【官方】**（[2814000](https://support.google.com/youtube/answer/2814000?hl=zh-Hans) · [2807691](https://support.google.com/youtube/answer/2807691?hl=zh-Hans) · [2807684](https://support.google.com/youtube/answer/2807684?hl=zh-Hans)）

| 方式 | 适用 | 时间线 |
|------|------|--------|
| 学完版权学院并等待 | 你认可移除有理 | 警示自收到之日起 **90 天**后失效（只需完成一次版权学院） |
| 请求对方撤销 | 你和版权方能沟通 | 撤销后警示解除、内容恢复（已删除的除外） |
| 提交抗辩通知 | 你认为是**误判**（含合理使用、公共领域等例外） | 这是**法律程序**；你的信息会提供给主张方；对方有 **10 个美国工作日**提供已起诉证据，否则内容恢复 |

- 若邮件显示移除要求是「**延迟执行**」，你有 **7 天**时间自行删除内容以免收到警示；其他情况下，删除视频**不能**解除版权警示。  
- 直播因版权被移除：频道收到警示并**停播 7 天**；再次收到则停播 **14 天**。  
- 一个视频同一时间只能有一条版权警示。  
- **不要提交虚假信息**：滥用流程可能导致账号终止或其他法律后果。

## 社区准则警示：警告 → 警示 → 终止

**【官方】**（[2802032](https://support.google.com/youtube/answer/2802032?hl=zh-Hans) · [185111](https://support.google.com/youtube/answer/185111?hl=zh-Hans)）

| 阶段 | 后果 | 何时失效 |
|------|------|----------|
| **警告**（通常首次违规） | 无功能限制；可选政策培训 | 完成培训起 **90 天**后失效；90 天内再违反同一政策可能变成警示 |
| **第 1 条警示** | **1 周**内不能上传、直播等 | 自发出之日起 **90 天** |
| **第 2 条警示**（同一 90 天内） | **2 周**不能发布内容 | 每条自发出之日起 90 天 |
| **第 3 条警示**（90 天内） | 频道**可能被永久移除** | — |

- 一次严重滥用可能不经警告直接终止。  
- 删除内容**不能**消除警示；删除后还**无法再申诉**。  
- 认为判错：收到警告或警示后 **6 个月**内可申诉；内容移除最长 **1 年**内可申诉。  
- 有未解除的社区准则警示时，不符合 YPP 申请条件（[72851](https://support.google.com/youtube/answer/72851?hl=zh-Hans)）。

## 常见追问

### 搬运 / 二次剪辑只要标注来源就没事？

不行。Content ID 和版权法看的是你是否有权使用；即使不触发警示，频道创收还要过「再利用内容」政策 → [再利用内容自查表](ypp-审核被拒与申诉.md#再利用内容自查表)。

### 收到版权主张，要不要把视频删掉？

版权主张一般只影响这条视频；删除不是唯一选项——可以不处理、移除被主张片段，或在有正当理由时提出异议（[6013276](https://support.google.com/youtube/answer/6013276?hl=zh-Hans)）。如果是**社区准则警示**，先别删：删了也不能消除警示，还会失去申诉机会。
