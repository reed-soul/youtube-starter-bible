## 漏斗（每条视频）

| 环 | 问一句 | 坏了就 |
|----|--------|--------|
| **曝光** Impressions | 对的人看得到缩图吗？ | 选题/实体词/目录 |
| **点击** CTR | 包装一目了然且诚实吗？（**分来源**看） | 重做封面**概念**与标题前半 |
| **留存** Intro→曲线 | 开场兑现了吗？Dip 处理了吗？ | 重开场 / 砍中段 |
| **满意** Satisfaction | 看完觉得值吗？还想再看一条吗？ | 结算更清晰；系列下一跳 |

```text
曝光 → 点击 CTR → 留存(AVD/AVP) → 满意 →（回流分发）
高 CTR + 低 AVD = 骗点，优先灭火
```

---

## 包装规则（发布前）

1. **门禁**：写不出 ≥8 标题草案 + ≥3 封面概念 → 先别拍  
2. **一瞥测试**：手机缩小图 0.5–1 秒说清「发生什么 / 得到什么」  
3. **互补**：缩图大字与标题不复读；重要词靠前；系列号靠后  
4. **如实**：承诺必须能在开场兑现；A/B 胜出看 **watch time 份额**，不是 CTR  
5. **中文**：约 20–35 字优先；通顺完整短语 > 关键词堆

---

## 留存钩子（开场 + 中段）

- **开场 15–30 秒**：画面/结果 → 赌注 → 路线图；禁 Logo→自我介绍→求订阅  
- **Shorts 导流例外**：前 5–10 秒先接住 Short 的问题  
- **中段**：每 45–90 秒一个信息增量；见 Dip 就删/剪/加速  
- **Spike**：剪 Shorts 或前移爽点  
- **片尾**：收获一句 + 下一跳 + 结束画面

---

## Shorts → 长视频桥

```text
Short（独立价值）→ Related Video → 末5秒 CTA → 长视频开场兑现 → 订阅/列表
```

- 每条长视频衍生 **2–4** 条 Shorts  
- 2026-10：**原创优先**；无实质搬运/刮擦高风险  
- 转化看长视频「流量来源 → Shorts」；按季度看趋势

## 节奏与实验

| 项 | 默认 |
|----|------|
| 长视频 | 每周 1（或可预测的 10 天 1） |
| Shorts | 每周 3–5 |
| 实验 | **单变量**；周复盘；月找模式 |
| A/B | 样本够再测；中途不手改 |
| 熔断 | 连续无法按日历 → **降频**，不消失式停更 |

冷启动周会只盯：**来源结构 · 分来源 CTR · Intro**

## 红线（碰了先停）

- 买播放 / 买粉 / 互订 / 刷评 / viewbot  
- 标题党骗点（高 CTR 低观看时长）  
- 无实质搬运、空洞 AI 罐头刷量  
- 无授权商用素材；把 Content ID 当成 fair use  
- 真实案件：不可核、骚扰当事人、嘲讽受害者换完播  
- 站外无关帖轰炸自荐；用奖励胁迫换互动

---

## 口令（背下来）

1. 推荐匹配 **视频 × 观众**  
2. **包装承诺 = 开场兑现**  
3. CTR 与 **观看时长一起看**，且 **分来源**  
4. Shorts 要有 **桥**，长视频开头要 **接住**  
5. 原创与质量 > 无脑产量  
6. 不买量、不互粉、不骗点
