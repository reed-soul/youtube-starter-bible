## 5分钟速读

> 先扫这几条再往下精读；细节与证据等级见正文。

- 约 90% 表现最好的视频用自定义缩图；标题须如实反映内容。【官方】
- 包装铁律：想法 ≤ 包装上限；一瞥测试；封面字与标题互补不复读。
- 两类标题：搜索型（清楚描述）与吸引型（激发好奇，更易翻车）。
- 中文标题经验：约 20–35 字、重要词靠前、系列号靠后；每条写 8–12 草案。
- Studio A/B 胜出看观看时长份额（watch time），不是 CTR。
- 诊断：高曝光低 CTR → 重做封面概念；高 CTR 前 30 秒崩 → 包装过度。

## 1. 官方基线

**【官方 · 缩图与标题诀窍】**

- 约 **90%** 表现最好的视频使用**自定义缩图**  
- 标题须**如实反映内容**；误导会导致观众离开并影响曝光  
- 标题尽量精简；**最重要的词靠前**；集数/品牌信息放后  
- 两类标题：**搜索型**（清楚描述）与 **吸引型**（激发好奇，适合浏览）  
- 缩图：风格匹配受众；可用三分法；少堆砌；主体大；文字可读；可随时间更新旧缩图  
- 慎用全大写、堆表情等降低可读性的写法  

**【官方】** 包装是 Appeal 的前线：站在新观众视角问「我会点吗？」

---

## 2. 包装铁律

**【行业实践】**（Paddy Galloway 等公开框架的教育向归纳）

1. **想法 ≤ 包装上限**：先写大量标题变体、草图多个截然不同的封面概念，再投入拍摄。  
2. **一瞥测试（glance test）**：手机缩小图，0.5–1 秒内能否看懂「发生了什么/我会得到什么」。  
3. **封面文字与标题互补，不复读**；中文封面大字通常宜少（约数个汉字级），高对比。  
4. **更好的包装可带来非线性回报**——这是经验法则，**不是**官方保证。  

**【神话】**「设计越花哨 CTR 越高。」  
**【纠正】** 清晰的冲突/结果预告，通常打败装饰性设计。

## 3. 两类标题

| 类型 | 何时用 | 写法 |
|------|--------|------|
| 搜索型 | 教程、评测、命名实体、How-to | 完整描述内容与对象 |
| 吸引型 | 故事、观点、反差、榜单 | 制造好奇但必须可兑现 |

同一条视频可写两种风格各若干条，用 A/B 或历史经验选择；**吸引力标题更容易翻车成标题党**，务必用开场兑现来约束。

搜索型标题的素材应从 [03 · 搜索驱动选题研究](03-定位选题与系列化.md) 的自动补全短语来，而不是凭空堆词。

---

## 4. 中文标题实操

- 面向华语观众：优先通顺中文；专有名词可保留外文  
- 短到约 **20–35 个汉字**优先（经验区间，非官方硬限制）；关键实体靠前  
- 系列名/集数靠后：`……｜第三集`  
- 避免：无信息感叹号墙、全大写英文堆砌、和封面逐字重复  
- 海外华人向：可在描述补充地区关键词，但标题仍服务点击清晰度  

每条视频建议写 **8–12 个标题草案**，冷读淘汰，再进设计。

## 5. 通用标题公式

| 公式 | 模板 |
|------|------|
| 结果承诺 | 「如何在【时间】做到【结果】（含【关键约束】）」 |
| 错误信念 | 「别再【常见做法】了：【更好做法】」 |
| 对比 | 「【A】还是【B】？给【身份】的诚实建议」 |
| 数字清单 | 「【N】个【年份】仍然有效的【主题】方法」 |
| 幕后/代价 | 「我做【事】失败的【N】个真实原因」 |
| 反差 | 「【看似普通】，其实【意外事实】」 |
| 时间压力 | 「只剩【时间】时，我如何【动作】」 |
| 搜索实体+钩 | 「【可搜名】：【一句冲突或结果】」 |

叙事向额外公式见旧版故事手册思路：物件线索、唯一视角、被禁止的问题——一律服从「可兑现」。

## 6. 封面系统

### 6.1 一图一主意

只传达一个主信息：结果、冲突、对比、前后变化、关键物件。

常用构图：

1. 人物表情/手势 + 清晰对象  
2. 左右对比（Before/After、A vs B）  
3. 大数字 + 单一符号  
4. 产品/界面特写 + 情绪点  
5. 文字只补标题没说的信息  

### 6.2 硬指标

- 自定义缩图；常见工作尺寸 **1280×720** 起  
- **【官方 A/B Help】** 若实验中任一缩图低于一定分辨率，可能导致实验缩图被降画质——保持高分辨率  
- 手机小图可读；高对比；避免花纹吞主体  
- 品牌色可统一，但**单集信息优先于庞大 Logo**  
- 人脸/关键物体尽量避开过度边缘裁切  

### 6.3 与标题分工示例

- 标题：实体 + 结果  
- 封面：情绪脸 + 「失败 3 次」短字  
- 不要两边都写完整长句

## 7. Studio A/B 与动态缩图（2026）

### 7.1 标题/封面 A/B【官方】

- 最多测 **3** 个标题、缩图或组合  
- **胜出标准 = 观看时长份额（watch time）**，不是 CTR  
- 桌面 Studio；需高级功能  
- 当前限制：一般不可对 Shorts、排期直播、进行中的首映等做该测试（以 Help 为准）；首映结束后转长视频或可测  
- 测试中途手动改标题/缩图会中断实验  
- 通常约两周内完成；无明显胜者时可能回落到你上传的第一套  

**【行业实践】** 变体要足够不同；可先测旧视频降低风险。第三方工具常优化 CTR，可能与 Studio 赢家不一致——**分发决策以 Studio 为准**。

### 7.2 Made on YouTube 2026【官方 Blog】

- **Ask Studio**：草稿反馈、标题缩图建议、分析解读等  
- **频道风格缩图生成 / 动态缩图**：向不同受众段展示更可能吸引其点击的选项（产品细节以你账号可用功能为准）  
- **视频剪辑 A/B**（多钩子/hook 版本）：宣布为即将推出；落地前勿写进 SOP 当作必做  

AI 生成缩图可用，但仍需通过一瞥测试与「如实」原则；避免惊悚擦边与内容不符。

## 8. CTR 诊断表

先在 Studio 视频分析 → 到达/内容相关卡片**按流量来源**看 CTR，再套下表。总 CTR 只作粗筛。【官方】搜索 CTR 常高于首页 CTR，属意图差异，不是故障。完整读数法见 [07 §6](07-频道装修与Studio.md)。

| 现象 | 优先动作 |
|------|----------|
| 曝光低、CTR 尚可 | 加强选题需求与可搜索实体；耐心攒样本 |
| 曝光高、CTR 低 | 重做封面**概念**（不是微调节奏色）；标题前半更锋利 |
| CTR 高、前 30 秒崩 | 包装过度；改开场或降承诺 |
| CTR 高、全程留存差 | 中段注水/节奏问题；按留存 Dip 砍 |
| 仅频道页 CTR 高 | 粉丝友好包装；另做「新观众向」变体 |
| A/B 显示 watch time 胜者 CTR 非最高 | **正常**：听官方胜出标准，勿只追 CTR |
