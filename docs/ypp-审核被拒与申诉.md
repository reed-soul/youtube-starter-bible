# YouTube YPP 审核要多久？被拒、申诉与「再利用内容」自查

> 相关：[YPP 进度计算器](ypp-进度计算器.md) · [「创收功能无法在您所在地区使用」](创收功能无法在您所在地区使用.md) · [09 §7 版权与再利用](09-变现与合规红线.md) · [13 §7 搬运与原创](13-中国大陆创作者专章.md#_7-搬运、二次利用与-shorts-原创)

## 一句话答案

**【官方】** 提交 YPP 申请后，审核**通常约 1 个月**；第一次被拒，可以在 **21 天内申诉**（**14 天内**答复，成功后 **30 天内**批准），或改好频道后 **30 天后**重新申请；不是第一次被拒、之前重新申请过、或申诉失败，要等 **90 天**（[72851](https://support.google.com/youtube/answer/72851?hl=zh-Hans) · [9235730](https://support.google.com/youtube/answer/9235730?hl=zh-Hans) · [9564590](https://support.google.com/youtube/answer/9564590?hl=zh-Hans)）。被拒最常见的原因是频道中**较大比例**的内容不符合创收政策，例如再利用他人内容。

## 审核员会看什么

**【官方】** 自动系统 + 人工审核员看**整个频道**（[72851](https://support.google.com/youtube/answer/72851?hl=zh-Hans)）。因为不可能看每一条视频，审核员可能重点看（[1311392](https://support.google.com/youtube/answer/1311392?hl=en)）：

- 频道**主题**  
- **观看次数最多**的视频、**最新**的视频  
- **观看时长占比最大**的视频  
- 视频元数据：**标题、缩略图、说明**  
- 频道「**简介**」部分

官方说这些只是例子，审核员也可能看频道的其他部分。

## 被拒后先做这三件事

**【官方】**（[9235730](https://support.google.com/youtube/answer/9235730?hl=zh-Hans)）

1. **读拒信**：邮件里会写明频道违反了哪些具体政策。  
2. **对照检查**：拿 [频道创收政策](https://support.google.com/youtube/answer/1311392?hl=zh-Hans) 和社区准则，检查视频、标题、说明、缩略图和标签。  
3. **修改或删除**违反政策的视频，再决定申诉还是重新申请。

官方也写明：修好频道**不保证**一定能获准创收。

### 申诉还是重新申请？

| 你的判断 | 走哪条路 | 时间（官方） |
|----------|----------|--------------|
| 认为审核**判错了** | 申诉 | 被拒后 **21 天内**（不论第几次申请）；**14 天内**答复；成功则 **30 天内**批准；失败则从被拒日起 **90 天**后可再申请 |
| 承认有问题，已经改好 | 重新申请 | 第一次被拒：收到拒信 **30 天**后；不是第一次或之前重新申请过：**90 天**后；重新审核约 **1 个月** |

**注意**：**【官方】** 审核申诉时按频道**当前状态**评估，所以**不要在提交申诉之前删除视频**（[9564590](https://support.google.com/youtube/answer/9564590?hl=zh-Hans)）。如果你打算删改视频，更适合走「重新申请」。

## 怎么申诉

**【官方】** 两种方式，具体以工作室显示的为准（[9564590](https://support.google.com/youtube/answer/9564590?hl=en)）：

**A. 视频申诉**（符合条件时）

- 格式：**只用视频**（不要把申诉内容写在说明里）、**少于 5 分钟**、设为**不公开列出**、上传到被申诉的频道、是**新上传**；  
- 语言：受支持语言包括**普通话**（或使用非自动生成的英文字幕）；  
- 内容：在**前 30 秒**内给出频道网址；对照具体政策条款，说明整个频道怎么符合；展示你**如何拍摄、如何剪辑**（可以露脸或配音）；  
- 提交：工作室 → 创收 → 开始申诉 → 填入不公开视频网址。

**B. 通过创作者支持团队申诉**：工作室 → 创收 → 「如果你认为我们弄错了，可以申诉」→ 开始申诉。

### 已在 YPP，收到「计划暂停」通知

**【官方】**（[9564590](https://support.google.com/youtube/answer/9564590?hl=zh-Hans)）

- 在**预定暂停日前 7 天内**提交申诉：暂停先搁置，**14 天内**答复；失败则被暂停，且**不能再申诉**，暂停日起 90 天后可重新申请。  
- 没在 7 天内申诉：频道被暂停；暂停后 **21 天内**仍可申诉，14 天内答复，成功则 30 天内恢复。

## 再利用内容自查表

**【官方】** 「再利用内容」指：把 YouTube 或其他网站上已有的内容拿来用，却**没有加入显著的原创评论、实质性修改，或教育 / 娱乐价值**。这项政策看的是**整个频道**；如果有违规视频，或审核员**看不出内容是你做的**，整个频道都可能失去创收（[1311392](https://support.google.com/youtube/answer/1311392?hl=en)）。

> 关键一句：**即使获得原作者许可，这项政策也照样适用**；它和版权是两回事，不看版权、许可或合理使用——你可能没收到任何版权主张，频道仍然违反再利用内容政策。

| ✅ 官方举例：可以创收（仍受版权等其他政策约束） | ❌ 官方举例：不能创收 |
|------|------|
| 用片段做**批判性评论** | 把喜欢的节目片段剪在一起，几乎没有叙述 |
| 重写台词、换掉配音的电影片段 | 从其他社交网站搬来的短视频合集 |
| 体育比赛回放 + 讲解选手的动作 | 不同歌手的歌曲合集（**即使有授权**） |
| 对原视频发表评论的**反应视频** | 已被很多创作者重复上传的内容 |
| 加入故事线和评论的他人素材剪辑 | 推广别人的内容（**即使有授权**） |
| Shorts 混剪里加入你自己的原创内容 | 从其他网站下载或复制、没有实质修改的内容 |
| 以上传者本人出镜为主的内容 | 主要靠无语音的反应、没有配音评论的内容 |
| 在画面中能看到创作者、或说明了创作者做了什么的再利用内容 | 只是朗读不是你创作的文字（如网页、新闻源） |
| 有实质剪辑、叠加音视觉效果、明显属于你频道的作品 | 只改了音调或速度、其余与原曲相同的歌曲 |

### 「不真实内容」（原「重复内容」） {#不真实内容}

**【官方】** 2025-07-15 起，「重复内容」更名为「**不真实内容**」，并明确包括**批量生产、重复性**的内容（[1311392](https://support.google.com/youtube/answer/1311392?hl=en)）。不能创收的例子：

- 教育价值、评论、叙事很少，视频之间几乎没有变化的相似内容；  
- 让角色一次次落入同样情境、同样结局（高度相似的故事模板）；  
- 几乎没有叙述、评论或教育价值的图片幻灯片、模板化故事、滚动文字；  
- 用通用或非原创模板生成、给人批量生产印象、没有加入创作者原创见解的 **AI 生成内容**。

允许的例子：片头片尾相同但主体内容不同；系列节目或产品测评，但每期有不同的故事、重点或概念。

### 30 秒自查（对照你的频道）

- [ ] 播放最多、最新、观看时长最大的 5 条视频，**看得出是我做的**吗？（出镜、配音、拍摄或剪辑过程）  
- [ ] 用了他人素材的视频，我加了**评论、讲解、故事线或实质剪辑**吗？只是「有授权」不算。  
- [ ] 频道里有没有「换个标题就能互换」的模板视频？  
- [ ] AI 生成内容里有没有我**自己的观点、研究或叙事**？  
- [ ] 标题、缩略图、说明和频道简介，是否如实描述内容？  
- [ ] Shorts 里有没有未经编辑的影视片段、搬运或无原创内容的合辑？（这些观看在 Shorts 分成中也**不计入**，[12504220](https://support.google.com/youtube/answer/12504220?hl=en)）

更系统的搬运 / 二次创作判断见 [09 §7](09-变现与合规红线.md) 与 [13 §7](13-中国大陆创作者专章.md#_7-搬运、二次利用与-shorts-原创)。

## 常见追问

**提交申请后，订阅掉到门槛以下会被拒吗？**  
**【官方】** 不会因此被拒；达标并提交后，数字下降不影响审核。但更改视频公开状态或删除视频可能影响申请状态（[72851](https://support.google.com/youtube/answer/72851?hl=en)）。

**有未解除的社区准则警示，能申请吗？**  
**【官方】** 不能，要等警示到期，或申诉成功移除警示后再申请（[72851](https://support.google.com/youtube/answer/72851?hl=zh-Hans)）。

**被拒后另开一个频道申请行不行？**  
如果是被停用创收或终止，官方明确禁止另开或借用频道规避（[1311392](https://support.google.com/youtube/answer/1311392?hl=en) · [2802168](https://support.google.com/youtube/answer/2802168?hl=en)）。

**中国大陆的频道能走这个流程吗？**  
先要满足地区资格。截至 2026-10-06，YPP 适用地区名单未见「中国」→ [「创收功能无法在您所在地区使用」是什么意思](创收功能无法在您所在地区使用.md)。
