# YouTube 设备与剪辑起步（手机 / 麦克风 / 灯光 / 免费剪辑）

> 相关：[02 冷启动](02-冷启动0到1000.md) · [05 脚本与剪辑纪律](05-脚本留存与完播.md) · [注册 · 品牌账号](youtube-注册与品牌账号.md) · [新手路线图](新手路线图.md) · [11 FAQ · Q11](11-常见问题FAQ.md#q11-没设备能开始吗)

## 一句话答案

**【行业实践 + 官方上传规格】** 没有「必须先买相机」：现代手机拍 **1080p** 通常已够起步；**清晰人声 + 基本光照 + 可读字幕**，通常比空有设备更能保住留存。免费剪辑优先用官方下载的 **剪映**（国内 [capcut.cn](https://www.capcut.cn/)）或 **CapCut**（国际 [capcut.com](https://www.capcut.com/)）、以及 **DaVinci Resolve** 免费版（[Blackmagic 下载页](https://www.blackmagicdesign.com/products/davinciresolve)）。导出对照 YouTube 官方建议：容器 **MP4**、视频 **H.264**、音频 **AAC**、常见目标 **1080p / 约 8 Mbps（24–30 fps）**（[1722171](https://support.google.com/youtube/answer/1722171?hl=zh-Hans)）。本页**不推荐具体购物型号、不放联盟链接、不讨论网络访问方式**。

## 1. 先定「够用」标准，再谈升级

| 优先级 | 要达到的效果 | 为什么 |
|--------|--------------|--------|
| **1. 人声听得清** | 说话不糊、环境噪音可控 | 听不清会直接抬跳出；比 4K 画质更影响「值不值得看完」 |
| **2. 脸/主体不糊、不背光** | 窗光或一盏柔光、相机别正对强光 | 过暗/过曝会让人快速划走 |
| **3. 画面稳定** | 固定机位、靠墙/书本垫稳，或简易三脚架 | 晃动比分辨率更伤观感 |
| **4. 再谈分辨率** | 长视频 **1080p** 即可；Shorts 竖版 1080×1920 常见 | 【官方】推荐分辨率含 1080p（1920×1080）（[6375112](https://support.google.com/youtube/answer/6375112?hl=zh-Hans)） |

**【行业实践】** 冷启动阶段用「可发布的清晰」验证选题与包装，再按真正卡点（噪音？背光？）升级，而不是按购物清单一次配齐。见 [02 §4](02-冷启动0到1000.md#_4-前-10–20-条选题规则) 与 [11 Q11](11-常见问题FAQ.md#q11-没设备能开始吗)。

## 2. 手机当相机：怎么拍就够用

1. **横拍长视频 / 竖拍 Shorts**：长视频默认 **16:9**；Shorts 用竖版。别在画面里预埋黑边（【官方】播放器会自适应，自加黑边会干扰适配，[6375112](https://support.google.com/youtube/answer/6375112?hl=zh-Hans)）。  
2. **锁曝光与对焦**：长按主体锁定，避免说话时画面忽明忽暗。  
3. **录制分辨率**：设置里选 **1080p**（或接近）；不必一上来 4K——文件大、剪辑慢、上传久，对冷启动收益有限。  
4. **距离与构图**：人声口播时手机距嘴约一臂内更稳；主体略偏中心，给字幕留底边安全区。  
5. **收声**：优先外接麦（下一节）；若暂时只用机身麦，选安静房间、关风扇空调、手机别塞口袋摩擦。

## 3. 麦克风与灯光：写预算区间，不推型号

本站**不写「必买某某牌」**，只给大陆读者可参考的**人民币量级区间**（市面价波动大，以你当地为准）。用途是「知道大概花多少就够用」，不是购物清单。

### 麦克风（人声优先）

| 档位（大约） | 常见形态 | 适合 |
|--------------|----------|------|
| **¥0** | 手机机身麦 + 安静房间 | 验证选题的前几条 |
| **约 ¥50–200** | 入门领夹 / 有线小胶囊麦（插手机） | 口播、桌面讲解；重点是「贴得近、线不松」 |
| **约 ¥150–400** | 入门 USB 桌面麦（接电脑剪辑监听更好） | 固定机位口播、配音 |
| **约 ¥300+** | 无线领夹套装 | 走动演示、双人；先确认你的手机接口（Type-C / Lightning）与系统权限 |

**【行业实践】** 升级顺序通常是：安静环境 → 近讲 → 外接麦 → 声学简单处理（窗帘/地毯），而不是先换相机。

### 灯光

| 档位（大约） | 做法 | 注意 |
|--------------|------|------|
| **¥0** | 面朝窗户的漫射日光；避免大逆光 | 阴天窗外光往往比正午直射更好控 |
| **约 ¥30–150** | 台灯 + 白纸/硫酸纸柔光；或小型台灯打轮廓 | 色温尽量一致（别一盏黄一盏白） |
| **约 ¥80–300** | 入门环形灯 / 小型柔光灯 | 功率不必大；能看清脸且不刺眼即可 |

**【行业实践】** 「一张干净的脸 + 听得清」比「三灯影棚」更贴近冷启动 ROI。

## 5. 上传到 YouTube：官方建议你对照这些

来源：YouTube 帮助《推荐的上传编码设置》[1722171](https://support.google.com/youtube/answer/1722171?hl=zh-Hans) · 《视频分辨率与宽高比》[6375112](https://support.google.com/youtube/answer/6375112?hl=zh-Hans)

| 项 | 起步常用建议（官方） |
|----|----------------------|
| 容器 | **MP4**；moov atom 靠前（快速开始） |
| 视频 | **H.264**，逐行扫描；色度 4:2:0 |
| 音频 | **AAC-LC** 等；采样率 **48 kHz**；立体声常见推荐比特率见原文表 |
| 分辨率 | 长视频 **1080p = 1920×1080**（16:9）；竖版 Shorts 用 9:16 |
| SDR 视频比特率参考 | **1080p**：标准帧率（24/25/30）约 **8 Mbps**；高帧率（48/50/60）约 **12 Mbps** |
| 帧率 | 与拍摄一致；隔行内容先反交错再上传 |

**【行业实践】** 冷启动导出：**1080p · 24/25/30 fps · H.264 · AAC · MP4** 通常足够。先保证声音与开场，再追求 4K/60fps。

发布勾选与可见性见 [07 频道装修与 Studio](07-频道装修与Studio.md)。

## 常见追问

### 必须买微单才能涨粉吗？

不必。【行业实践】多数冷启动瓶颈在选题、包装与开场兑现，不在传感器尺寸。见 [02](02-冷启动0到1000.md) · [04](04-标题封面与包装.md)。

### 剪映导出有水印怎么办？

以你当前 App/桌面版官方界面与账号权益说明为准；本站不保证各版本商业条款。可选：换用 [DaVinci Resolve 免费版](https://www.blackmagicdesign.com/products/davinciresolve) 自行导出无水印成片（功能学习曲线更陡）。

### 竖屏能不能当长视频发？

能上传；播放器会适配。若目标是传统横屏浏览场景，优先 16:9；Shorts 用竖版更合适（[6375112](https://support.google.com/youtube/answer/6375112?hl=zh-Hans)）。
