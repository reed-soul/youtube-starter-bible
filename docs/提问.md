去 GitHub **Discussions → Q&A** 提问（已启用）。提问前请用下方模板；维护者优先用官方来源回答，或标明待核。

## 提问模板（复制）

```text
【卡在哪一步】注册 / 前10条 / 涨粉 / YPP / 审核 / 税务 / PIN / 电汇 / 结汇 / 版权 / 其他：

【Studio 或 AdSense 原文提示】（可打码账号、邮箱）


【频道「国家/地区」设置】（不要发可识别隐私）


【已试过】


【已读官方帮助】（粘贴 URL）


【期望】希望进 FAQ / 只要私下讨论 / 投稿公开时间线（附原文链接）
```

- VPN / 科学上网步骤、改频道国家/地区「曲线」、假地址、虚拟号养号  
- 如何少报、不报税或勾选具体结汇用途代码以「走通」  
- 代办开通 YPP / 代收款
