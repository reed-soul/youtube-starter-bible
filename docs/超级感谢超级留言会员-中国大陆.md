## 与 YPP / 拓展档门槛的关系

**【官方 · 72857】** [YouTube 创收方式](https://support.google.com/youtube/answer/72857?hl=zh-Hans) 说明 YPP 含广告、Premium、Shopping、**粉丝打赏**（含超级留言、超级感谢、频道会员等）等路径；拓展档常见 **500 订阅 + 3,000 公开观看小时或 300 万 Shorts 观看**等门槛（另见 [94522](https://support.google.com/youtube/answer/94522?hl=zh-Hans)）。

**【重要】** 门槛达标 **≠** 地区可用。须同时满足**创作者所在地区在官方名单内**、YPP/功能资格、后台开关等。**大陆创作者**即使粉丝达标，若地区不在名单，Studio 可能**不出现**「超级」系列标签。

YPP 居住地 → [YPP 中国大陆资格](ypp-中国大陆资格.md) · 报错 → [创收功能无法在您所在地区使用](创收功能无法在您所在地区使用.md)。
