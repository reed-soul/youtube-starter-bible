## 问答

> 每条**第一句直接答**；便于搜索摘要。日期未写死处，请打开官方链复核。


### Q0. 怎么注册 YouTube 频道？个人频道还是品牌账号？要开两步验证吗？

**A.** 【官方】登录后：头像 → 设置 → 添加或管理频道 → 创建频道；想多人管理或换名字用品牌账号。申请 YPP 须开启两步验证。逐步说明 → [注册 · 品牌账号 · 两步验证](youtube-注册与品牌账号.md)。

### Q1. 国内怎么做 YouTube？从零到变现要过哪些关？

**A.** 先能合法使用服务并持续发布**原创**内容，再用 Studio 做包装与复盘；变现取决于是否满足 **YPP 适用地区** + 门槛 + 审核 + AdSense/税务/收款。内容方法见 01–08 章；大陆特有关卡见本章 §1–§6。

### Q2. 中国大陆能申请 YouTube 合作伙伴计划吗？

**A.** 【官方】须居住在[已推出 YPP 的国家/地区](https://support.google.com/youtube/answer/7101720?hl=zh-Hans)。截至 **2026-10-06** 该页列表含香港、台湾等，**未见「中国」条目**。专题展开 → [YPP 中国大陆资格](ypp-中国大陆资格.md) · Studio 提示「创收功能无法在您所在地区使用」→ [是什么意思](创收功能无法在您所在地区使用.md)。请以当日官方列表与账号后台提示为准；勿依赖自媒体「选区」口令。

### Q3. 2027 年 YPP 门槛变了吗？大陆创作者要注意什么？

**A.** 【官方】自 **2027-02-01** 起，**新申请人**广告/Premium 为 **8,000** 小时或 **2,000 万** Shorts（仍须 1,000 订阅）；**已在 YPP 者进入门槛不受影响**；粉丝赞助/Shopping 门槛不变。大陆侧仍须先过**适用地区**关。对照表 → [YPP 中国大陆资格 · 2027 新门槛](ypp-中国大陆资格.md#_2027-02-01-起新门槛)。

### Q4. 大陆人做油管，AdSense 怎么收款？

**A.** 【官方】收款国家为**中国**时，支持**电汇**与 **Hyperwallet**。步骤与手续费 → [AdSense 电汇收款](adsense-电汇收款.md)。先完成身份/地址验证与税务信息，余额达支付门槛后按月处理付款。银行能否顺畅入账是另一层实务问题。

### Q5. YouTube 收入如何结汇成人民币？银行收不收电汇费？

**A.** 【官方 · 电汇费】Google **不收**电汇费；工行公开页写明不收境外汇入手续费；招行公开页写明不收入账手续费（中间行除外）——**中间行仍可能扣费**。问柜台要当日《服务价目表》+ 该户能否收 Google 来账。

【官方 · SAFE 结汇】个人结汇 / 境内个人购汇有每人每年等值 **5 万美元**的**便利化额度**（凭身份证件即可办）；这**不是**硬上限——真实合法经常项目可凭身份证件 + 有交易额的资金来源材料办理**不占用**额度的结汇（《经常项目外汇业务指引（2020）》·《个人外汇管理办法实施细则》第十条列有「专有权利使用和特许收入」「职工报酬」等材料类型）。电汇**汇入**与**结汇**是两步；5 万美元口径主要约束结汇/购汇。详表 → [AdSense 电汇收款](adsense-电汇收款.md)。**以开户行要求为准**；本站不指导用途代码。

### Q6. W-8BEN 中国居民要填吗？预扣多少？

**A.** 通常填 W-8BEN（以税务工具为准）。**未提交**：个人账号可按全球收入约 **24%** 预扣。【官方】**已提交并主张协定**：YouTube 版税类常对应特许权使用费框架，IRS 表列中国 Royalties **10%**（仅美国观众来源部分）。以后台「管理税务信息」显示的预扣税率为准。中国国内法下，有公民身份号码的，**公民身份号码即自然人纳税人识别号**（个税法第九条 · 税总公告 2018 年第 59 号）；OECD China-TIN 亦写 ID card → TIN is the ID number；中国不在 IRS「不签发外国税号」名单。字段级说明 → [W-8BEN 填写图解](w8ben-填写图解.md)。

### Q7. YouTube 收入要在中国报个税吗？算特许权使用费吗？

**A.** 中国税收居民的境外所得有申报与抵免框架（2020 年第 3 号等）。**税目不能写死**：实施条例分别定义特许权使用费、劳务报酬、经营所得、稿酬——依合同与业务实质。总局公开库未见「YouTube=唯一税目」钉死条款。问 12366/顾问。本文非税务意见。

### Q8. 油管搬运算原创吗？能过 YPP 吗？

**A.** 无实质原创评论或改造的二次利用内容，整频道可能无法通过创收审核；有版权许可也不能自动过关。【官方】创收政策。Shorts 在 2026-10 后对无实质搬运分发更不友好。官方可/不可创收例子与被拒后申诉 → [YPP 审核与申诉](ypp-审核被拒与申诉.md#再利用内容自查表)。

### Q9. B 站和 YouTube 可以同步发一样的片子吗？

**A.** 可以分发同一选题，但建议按平台改编包装与结构，并确保素材授权覆盖；完全同质一键同步不是好策略，也无助于原创判定。

### Q10. YouTube AI 配音要不要标注？

**A.** 克隆**自己**声音做旁白：官方示例通常无需披露。让真实人物「说了没说过的话」等写实合成：**必须**在 Studio 披露 AI 使用情况。

### Q11. 是不是必须先搞香港银行卡才能收款？Hyperwallet 呢？

**A.** **不是。** 中国地址下官方支持电汇与 Hyperwallet（[1714397](https://support.google.com/adsense/answer/1714397?hl=zh-Hans) · [16691394](https://support.google.com/adsense/answer/16691394?hl=zh-Hans)）。专页 → [必须香港银行卡吗](必须香港银行卡吗.md) · [Hyperwallet 中国](hyperwallet-中国.md)。

### Q12. PIN 码收不到怎么办？

**A.** 【官方】PIN 经**平邮**，常见约 **2–4 周**；满 **3 周**可在「收款 → 验证检查」申请替代 PIN（每 3 周一次）；第 **4 次**替代仍无 → 官方排查工具；生成后约 **4 个月**未验证可能停投（[1348257](https://support.google.com/adsense/answer/1348257?hl=zh-Hans) · [9668823](https://support.google.com/adsense/answer/9668823?hl=zh-Hans)）。地址须能收平信。摘要仍见 [AdSense 电汇 · PIN](adsense-电汇收款.md#pin、税务与门槛（收款前置）)。

### Q13. 付款大概哪天到？

**A.** 【官方】上月 YouTube 最终收入约本月 **7–12 日**入 AFY 余额；**20 日**前须达 $100 且无暂停；**21–26 日**发起付款；电汇最多约 **15 个工作日**到账。选月推算 → [付款日历](youtube-付款日历.md)；逐项排查 → [收款自查清单](收款自查清单.md)。

### Q14. 国内做油管 / YouTube 合法吗？

**A.** 本站**不能**给个案「合法/违法」结论；请拆成网络接入、内容传播、税务外汇、平台条款四层分别核对 → [国内做油管合法吗](国内做油管合法吗.md)（**非律师意见**）。

### Q15. 超级感谢 / 超级留言 / 频道会员大陆能用吗？

**A.** 截至 **2026-10-07** 官方创作者名单与观看者购买名单均**未见中国大陆**（含港台对照）→ [超级感谢超级留言会员-中国大陆](超级感谢超级留言会员-中国大陆.md)。

### Q16. 频道被盗或被终止怎么办？

**A.** 被盗先恢复 Google 账号（**76187**）；终止申诉 **1 年内最多 2 次**（**2802168**）——**不是** YPP 被拒申诉 → [youtube-频道被盗与终止申诉](youtube-频道被盗与终止申诉.md)。
