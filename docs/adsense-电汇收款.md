## 一句话答案

**【官方】** 当 AdSense / AdSense YouTube 广告账号的**收款地址国家为中国**时，付款方式表中**电汇**与 **PayPal Hyperwallet** 为适用选项（支票/普通 EFT 等见原表）。银行（或分行）须与收款地址**位于同一国家/地区**，否则 SWIFT 可能无法保存。【官方】[付款方式国家表](https://support.google.com/adsense/answer/1714397?hl=zh-Hans) · [付款 FAQ](https://support.google.com/adsense/answer/7164701?hl=zh-Hans)

**【神话】**「中国 AdSense 完全收不到钱 / 必须先办香港卡」——与官方付款国家表及 Hyperwallet 中国可用性公告不符；专页 → [必须香港银行卡吗](必须香港银行卡吗.md)。境外卡须与真实居住与税务安排一致；本站不教虚假身份。【合规】

流程细节参考了 [发财麦克的实操记录](https://facaimike.com/youtube-payment.html/)，已按官方帮助中心核对。**本站不收录**「改频道国家/地区到港台、VPN、虚假地址」类操作。

## 月度付款周期（电汇）

<PayoutCycle />

**【官方要点】**

- 付款周期**按月**；上月估算收入在**下月初**定稿计入余额。  
- YouTube（AdSense for YouTube）上月最终收入常见于本月约 **7–12 日**充入 AFY 余额（与普通 AdSense「约 3 日」定稿时间线不同，以 Help 为准）。  
- **20 日**前完成收款信息变更；20 日余额须达起付门槛，否则结转下月。  
- **21–26 日**发起电汇；若 21 日为周末/节假日，可顺延至下一工作日。  
- 电汇到账以银行与中间行为准，Help 写明可允许最多约 **15 个工作日**。

## 设置电汇（官方步骤框架）

以 AdSense Help「通过电汇接收款项」为准（按钮文案可能微调）：

1. 登录 AdSense 或 AdSense YouTube 广告账号（YouTube 创收关联的账号）。  
2. **收款 → 收款信息 → 管理收款方式 → 添加收款方式**。  
3. 选择**电汇至银行账户**，按提示填写：账户所有人姓名、银行名称、**SWIFT-BIC**、账号等（字段因国家而异）。  
4. 信息须与银行预留**完全一致**；如需 FFC/FBO 指示，按银行要求填写。  
5. 【官方】**电汇收款账户一般无需测试存款验证**。

主文献：[通过电汇接收款项](https://support.google.com/adsense/answer/3372975?hl=zh-Hans) · [为 YouTube 广告账号添加收款方式](https://support.google.com/youtube/answer/14728152?hl=zh-Hans)

**【行业实践 · 填写提示】** 户名拼音、银行英文名、SWIFT 以开户行当日告知为准；本站已核总行代码见 [银行 SWIFT 速查](银行SWIFT速查.md)，仍勿照抄未核验列表。一手记录里常见「拼音姓在前」等写法，仍以银行预留与 AdSense 提示一致为准。

### 个人结汇：便利化额度 ≠ 上限（SAFE 公开口径） {#safe-fx}

> **【非外汇意见 · 以开户行要求为准】** 下列只摘录国家外汇管理局公开规章；银行审核材料、国际收支申报用途代码、是否要求额外说明，**以你开户行当日要求为准**。本站**不**指导你勾选哪一个用途代码。

**【额度】**

- 《个人外汇管理办法实施细则》第二条：对个人结汇和境内个人购汇实行年度总额管理，**每人每年等值 5 万美元**；总额内凭本人有效身份证件办理（[天津分局转载文本](https://www.safe.gov.cn/tianjin/2024/0430/2464.html) · 汇发〔2007〕1 号印发，后经修订）。  
- 《经常项目外汇业务指引（2020 年版）》第五十四条将同一口径表述为「年度**便利化额度**」，每人每年等值 5 万美元（[国务院公报转载](https://www.gov.cn/gongbao/content/2020/content_5560296.htm)）。  
- 外管局分支机构公开问答写明：等值 5 万美元是便利化额度，**不是**「每人每年只能结/购汇 5 万美元」的硬上限；真实、合法的经常项目项下，凭规定材料仍可办理（例：[山西分局《常见外汇业务办理指南》](https://www.safe.gov.cn/shanxi/file/file/20230704/261d099ca05b479c82f28d0b5e16cd57.pdf)）。

**【经常项目 · 不占用便利化额度的结汇】**

- 指引第五十六条：境内个人凭本人有效身份证件和**有交易额的结汇资金来源材料**，可办理**不占用**年度便利化额度的经常项目结汇。  
- 《实施细则》第十条对境内个人经常项目**非经营性**结汇超过年度总额时，列明银行可审核的证明材料类型，其中包括：  
  - **专有权利使用和特许收入**：付款证明、协议或合同；  
  - **职工报酬**：雇佣合同及收入证明；  
  - 以及捐赠、赡家款、法律/会计/咨询服务收入等其他类型（全文见上引细则第十条）。  
- 汇发〔2021〕13 号还优化了「境外工作的境内个人」在同一银行再次办理不占额度的**薪酬结汇**手续（可免于重复提交材料），并要求银行对真实合法经常项目坚持实质重于形式（[汇发〔2021〕13 号](https://www.safe.gov.cn/safe/2021/0402/18672.html)）。

**【类似情形的公开统计口径 · 非 AdSense 专用指令】** 国家外汇管理局天津市分局《结售汇数据统计提示12》（2019-11-18）案例 2：境内居民向国外杂志投稿获**稿费**并结汇，资金性质属「版权、著作权、稿费收入（不涉及版权、著作权的转让）」，计入横栏 **「124 专有权利使用费和特许费」**、纵栏「05 居民个人」（[原文](https://www.safe.gov.cn/tianjin/2019/1118/1294.html)）。这是**银行统计/申报培训案例**，不是「YouTube 必须勾此码」的总局对 AdSense 点名规定；亦非「职工报酬」——公开提示中「职工报酬」对应**受雇于境外**取得工资薪金类汇入（另见天津市分局国际收支申报提示）。YouTube / AdSense 收入在你开户行要交哪些材料、申报哪一码，**仍由开户行审核**——本站**不**替你选定用途代码，也**不**保证柜台采纳上述 124 口径。

**【收款（汇入）与结汇是两件事】**

- 上述 5 万美元口径约束的是个人**结汇**与境内个人**购汇**的便利化额度，不是「境外电汇不能汇入超过 5 万美元」。  
- 细则对储蓄账户外汇汇**出**另有当日累计等值 5 万美元等规定（第十四条）；汇**入**解付后是否结汇、结多少，按结汇规则与银行审核办理。  
- Google 电汇到账后，你可选择保留外汇或结汇；结汇环节才触及便利化额度 / 真实性材料。

**【银行可能要求什么】** 公开规章指向的是身份证件 +「有交易额」的来源/用途材料（合同、协议、付款证明、收入证明等）。具体清单、翻译件、税务凭证是否需要，**以开户行要求为准**。

## PIN、税务与门槛（收款前置）

**【官方 · PIN】** 余额达验证门槛（USD 常见地址验证 **$10**）后寄送 6 位 PIN；通常约 **2–4 周**送达（[1348257](https://support.google.com/adsense/answer/1348257?hl=zh-Hans)）；满 3 周可重寄；生成日起 **4 个月**内须完成验证，否则可能停止展示广告。输错三次会停投广告（[9668823](https://support.google.com/adsense/answer/9668823?hl=zh-Hans)）。第 4 次重寄仍未收到 → 使用官方 PIN 排查工具。Google **不提供**运单号。[PIN 概览](https://support.google.com/adsense/answer/157667?hl=zh-Hans)

**【官方 · 税务】** 启用创收须提交美国税务信息；非美个人常见 **W-8BEN**。未提交时预扣可能显著更高；提交后对适用美国来源收益常见协定区间（中美条约 Royalties 框架多见 **10%** 上限讨论——**非个人税务意见**）。→ [W-8BEN 字段图解](w8ben-填写图解.md) · [大陆 FAQ](13-大陆FAQ.md) · [提交税务信息](https://support.google.com/youtube/answer/10390801?hl=zh-Hans)

**【官方 · USD 门槛简表】** 税务信息 $0 · 验证 $10 · 选收款方式 $10 · **起付 $100** · 撤销账号 $10。[付款最低限额](https://support.google.com/adsense/answer/1709871?hl=zh-Hans)

## 常见卡点自查

可勾选、可打印、进度可回访的版本 → [收款自查清单](收款自查清单.md)。

- [ ] 付款方式国家表「中国」行已打开，确认电汇 / Hyperwallet  
- [ ] 银行与收款地址**同国**；SWIFT / 户名 / 账号与银行预留一致  
- [ ] 税务信息（如 W-8BEN）状态有效，无因税表暂停付款  
- [ ] 地址 PIN：生成未满 4 个月；未满 3 周勿盲目重寄；运单号官方不提供  
- [ ] 每月 **20 日**前改完收款信息；当日余额 ≥ **$100** 且无暂停  
- [ ] 电汇发起后不满约 **15 个工作日**勿断言失败；超时再按电汇 FAQ 找银行 / Google  
- [ ] 结汇：理解「5 万美元」是便利化额度而非硬上限；超额或走经常项目真实性材料时问**开户行**要清单；勿照搬他人用途代码勾选  
- [ ] 理解 YPP **地区资格** ≠ 收款地址国家 → [YPP 资格页](ypp-中国大陆资格.md)
