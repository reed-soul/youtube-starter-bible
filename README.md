# 小白油管起步，一路玩到专家

> 一份面向 2026 年开频道者的开源中文指南：从 0 订阅到能独立运营的「专家级基本功」。  
> **状态**：知识库 / 静态站友好 · 官方优先 · 可复用检查清单  
> **基准日期**：2026-10-05（Asia/Shanghai）

---

## 这是什么

本仓库是一份**开源质量**的 YouTube 起步指南，目标不是贩卖「算法秘籍」，而是把：

- YouTube **公开文档**（Help / Creator Blog / CEO 公开信）
- **仍有效的行业实践原则**（标注为二级来源）
- **常见神话的拆解**

整理成可阅读、可审计、可贡献的中文手册。

读完并认真实践后，你应能：理解推荐系统的真实心智模型、完成冷启动到约 1000 订阅的可重复作业、独立做选题/包装/留存/Shorts 漏斗/Studio 实验/变现合规判断。

**本指南覆盖通用品类**（教学、科技、生活、游戏、叙事/悬疑、Vlog、商业等），叙事/悬疑只是示例之一，不是唯一路径。

## 2025–2026 必读更新（摘要）

- **Shorts 原创优先排序**（约 2026-10-01）：减少无实质改动的搬运/聚合 Shorts 分发。  
- **Made on YouTube 2026**：Studio Ask / 动态缩图 / 标题封面 A/B；视频剪辑 A/B「即将推出」。  
- **CEO 2026 公开信**：AI 是表达工具而非替代；主动管理「AI slop」与低质重复内容。  
- **Shorts → 长视频 Related Video 指南**（2026-07-14）：官方四步转化法。  
- **变现质量信号**：重复/模板化、令人不适的内容、敏感话题 AI 人设等「不真实内容」影响 YPP。

细节见各章与 [SOURCES.md](docs/SOURCES.md)（含章节主张→文献对照表，核对日 2026-10-05）。
